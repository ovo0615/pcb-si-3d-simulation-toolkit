# 2027 功能藍圖

> **這是規劃方向，不是交期承諾，內容可能調整。** 季度與項目會依設計、資源及驗證結果變動；列出的項目包含新功能與既有功能改善，不代表已完成。

★＝客戶需求

## 2027 Q1：批次工作與結果回查

| 功能 | 價值 | 驗收條件 |
|---|---|---|
| ★ 跨專案持久佇列 | 一次安排多個專案；作為後續合批的共用基礎 | 排序、失敗隔離與重開恢復正確，結果不串錯 |
| ★ 同板 PCIe／USB／MDI 分訊號裁切合批 | 各介面獨立分析再一起跑；重用裁切能力 | 各組 net／Port／回流正確，獨立結果可回查 |
| ★ 命名不規則的外部 S 參數快速接線 | 由名稱與電氣線索建議接線，減少逐埠點選 | 與人工正確對照比對；全反射等異常結果不產生建議；低信心配對標黃供確認，有歧義不猜 |
| HFSS 分段結果有效性與重跑提示 | 看清可用與失敗的分段，不只看求解狀態 | 沒有有效掃頻或 Touchstone 不算成功，失敗原因可回查 |
| 執行歷史、快照與 net 不符原因 | 重開後找得到設定與結果；說明為何不能沿用 | 不取錯 net 的結果，舊紀錄不猜補 |

外部 S 參數快速接線完全在本機執行：解析元件位號、pin、net 與差動命名（`_P/_N`、`+/-`、`DP/DN`），再以低頻傳輸與耦合量找候選。**這是從結果推接線**：來源檔本身有錯（全反射、埠沒接上、頻帶不足）時，推出的接線也會錯，因此先檢查來源，有異常就不推並標示原因。

候選但未排入：TDR 免選配對、Port 吸附提示與日誌上限先以小修處理。已知主流程缺陷優先修復，不等季度。

## 2027 Q2：變體與大板全流程

| 功能 | 價值 | 驗收條件 |
|---|---|---|
| ★ 多疊構與板版組合批次 | 一次比較不同版本與厚度 | 幾何重開核對，設定與結果分明，不改原板 |
| ★ 執行中追加與保留已完成結果 | 長批次中途加入新工作，不必重排 | 追加項目實際執行，重開後無重複或遺失 |
| ★ 設定驅動的一次到報告流水線 | 從 Net List 與設定直接產出報告 | 正常案例無須人工介入；缺規格或無效結果不判通過 |
| 大板進度、可取消與資源提示 | 看清等待階段與記憶體需求 | 階段計時、記憶體與取消狀態可查，逾時不當成已停止 |

候選但未排入：任意混排介面、板版差異自動沿用。效能改善先量基準，不承諾固定倍數。

## 2027 Q3：兩板接合與眼圖

| 功能 | 價值 | 驗收條件 |
|---|---|---|
| ★ 兩板幾何接合到報告 | 評估接合處寄生效應，補足單純串接的不足 | 與原生模型同設定對照；錯接或缺參考時拒絕 |
| PCIe Gen3～5 AMI 工程參考等化與預覽 | 比較有來源依據的等化設定 | 未知參數阻擋，發散或空白眼圖判為無效，不作認證用途 |
| IBIS／DDR 多道眼圖與判讀 | 固定模型與碼型後評估整個通道 | 探測點、corner 與碼型一致；有限 UI 不當統計簽核 |
| 背鑽與 TDR 沿線批次截面 | 從阻抗異常追到幾何改善方案 | 逐點對照，部分失敗有處置，鑽深與殘樁前後核對 |

候選但未排入：UCIe／PCIe Gen6、非理想電源／SSO、跨參考平面偵測，需另行研究模型與基準。

## 2027 Q4：多板、量測與異機協作

| 功能 | 價值 | 驗收條件 |
|---|---|---|
| ★ 三板以上組合求解 | 延伸到多板鏈路 | 三板代表案例與原生模型對照，兩板功能不退化 |
| 量測 TDR 與 I/V、V/T 模型導入 | 對照實物量測，建立可追溯的模型 | 單位、corner 與治具一致；合成示範不當實測 |
| 規格模型與 SerDes／COM 判讀 | 回查參數來源與對應標準 | 各模式獨立驗證，缺值不判 Pass，不宣稱廠商模型或認證 |
| 異機求解包、回收與結果沿用 | 可靠地交給另一台電腦計算 | 實際異機求解、回收與沿用；來源不符時拒絕 |

候選但未排入：PhiPlus 維持 Beta 評估；更多規範 preset、VTF／jitter／CISPR 25 與新輸出格式另行研究。

## Beta 轉正式的原則

Beta 功能要轉為正式支援，須固定支援範圍與限制、通過正常及失敗／取消情境的驗證、至少兩個代表案例各在兩次獨立執行中結果一致、必要時有獨立數值基準，並完成一致的文件與交叉審查。未達門檻就維持 Beta，季末不自動升級；目前哪些功能屬於 Beta 見 [README](../README.zh-TW.md)。
