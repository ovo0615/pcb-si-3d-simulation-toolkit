# Port 建立與求解設定

[回操作說明索引](../../操作說明.md)

<a id="這一章做什麼"></a>
在最終幾何上建立通道端點，再核對掃頻與收斂。裁切、疊構、背鑽或清理還沒做完，就先完成 [02 前處理](02-載入與裁切.md)。

<a id="操作步驟"></a>
## 建立 Port

1. 載入本次最終 `.aedb`，確認訊號與參考網路。
2. Port 類型保留「自動（建議）」；必要時依下表指定。
3. 按「建議端點（最多 2 個）」，核對通道兩端元件與訊號腳。不要全選所有候選元件。
4. 選設定檔或調整掃頻、網格與收斂，按「建立 Port 並套用求解器設定」。
5. 核對建立摘要：端點、Port 數、參考網路／層與預期一致。

| 類型 | 用法 |
|---|---|
| 自動（預設） | 腳數破百的元件使整板採 Pin Group，其餘 Coax；判斷寫入日誌 |
| Coax | 元件腳與參考導體的同軸型 Port |
| Circuit | 明確需要電路埠時指定 |
| Pin Group | 細間距 BGA 等；負端用該元件參考腳，整組一致，不與 Coax 混用 |

![建議端點與 Port 標記](../../graph/gui-13-port-endpoints.png)

<a id="每個-port-都要有參考"></a>
## 每個 Port 都要有參考

參考端是回流，不能只核對正端。細間距球陣列的座標負端可能落在 antipad，SIwave 可能排除該 Port；**求解成功不代表輸出埠數正確**。建 Port 後、匯出後都比較預期數量。數量不符先查參考與類型，不靠重新串接補回。

<a id="介面預設值"></a>
## 掃頻與 HFSS 預設

| 設定 | 現行初始值 |
|---|---|
| 掃頻 | `Interpolating` |
| 第一段 | `Linear Count`：0 Hz～1 Hz，2 點 |
| 第二段 | `Log Scale`：1 Hz～100 MHz，每 decade 20 點 |
| 第三段 | `Linear Step`：100 MHz～50 GHz，每 50 MHz |
| HFSS 自適應／網格 | 寬頻／`Phi`，PAR 啟用 |
| Error Tolerance／Max Refinement | 0.1%／15% |
| Min Converged／Max Passes／Max Delta S | 2／20／0.02 |

第三段上限隨[設定檔](#內建規格設定檔)帶入，或在[由資料率導出](#判斷頻寬)時一併調整。上限 ≥20 GHz 用 50 MHz；低於 20 GHz 分段縮小低頻步距，不把初始 50 MHz 一律套用。交付結果需記下實際頻段與步距。特定求解設定不接受 0 Hz 時，記錄錯誤再處理，不能默默刪掉。

<a id="自適應方式預設是寬頻"></a>
寬頻自適應範圍隨掃頻上限推導；也可選多頻或單頻。**收斂不代表高頻反射一定正確**，自適應範圍需覆蓋本次分析需求。套用後查看日誌，若方式回退，先核對實際值再求解。掃頻給 HFSS／SIwave 使用，其餘 HFSS 設定不等於 SIwave 設定。

<a id="判斷頻寬"></a>
## 判斷頻寬

求解器建議看的是「這次要用到幾 GHz」，不是掃到幾 GHz。在「模擬設定」的「判斷頻寬（求解器建議用）」二選一；分段頁只顯示，不能改。

| 來源 | 怎麼設 | 畫面顯示的來源 |
|---|---|---|
| 依規範 | 「設定檔」選內建規格並按「套用」 | 規範 DDR4-3200 |
| 依資料率自訂 | 填資料率（`1866` 或 `1.866` 都收），按「由資料率導出」 | 資料率 1.866 Gbps 導出 |
| 進階覆寫（優先於上面兩者） | 展開「進階：手動覆寫判斷頻寬」填 GHz；留空＝不覆寫 | 進階覆寫 |
| 都沒有 | — | 未指定，跟掃頻上限 |

| 規則 | 說明 |
|---|---|
| 判斷用途 | ≤7 GHz 建議 SIwave，否則依幾何複雜度。**切面一律以掃頻上限驗收**，不看判斷頻寬 |
| 兩邊各自保留 | 切到另一邊只改「用哪一個」，切回來原值還在 |
| 高於掃頻上限 | 黃字警告：需求頻段不會被求解涵蓋。先把掃頻上限拉高，不要只改判斷頻寬 |
| 導出時的掃頻表 | 掃頻表還是預設三段時會問「要把末段上限改為 X 嗎」，按「取消」只更新判斷頻寬；表改過或來自規範就不動，只附建議上限 |
| 覆寫填 0 或負值 | 紅字「目前沒有採用」，沿用規範或資料率的值 |
| 資料率改了沒重新導出 | 提示「請按『由資料率導出』更新」 |

![模擬設定：套用 DDR4-3200 後，判斷頻寬 8 GHz（依規範）、切面以掃頻上限 16 GHz 驗收](../../graph/gui-14-solve-profile.png)

<a id="內建規格設定檔"></a>
## 設定檔

在「設定檔」選「內建規格（唯讀）」並套用，檢查掃頻上限與自適應值。內建規格不能覆寫／刪除；要調整就另存個人設定檔。內建檔不包含裁切外擴與形狀。

套用內建規格會把判斷頻寬切到「依規範」並帶入該規範的值。若會換掉已經在用的判斷頻寬（例如目前是依資料率自訂），先跳確認框；按「取消」整份不套用。掃頻上限低於 20 GHz 的規格（如 DDR4-3200）帶入的是多段 `Linear Step`，低頻步距較小。

| 內建規格 | 掃頻上限 |
|---|---|
| DDR4-3200／DDR5-6400 | 16／32 GHz |
| LPDDR4X-4266／LPDDR5X-8533 | 22／43 GHz |
| PCIe Gen3／Gen4／Gen5 | 20／40／50 GHz |

這些是分析起點，不能取代專案規格。個人檔套用後也要看頻率單位與步距，避免把前一案的設定帶入。

## 核心與授權

排程預設 12 cores；先用「說明」查所需授權與可用數量。只有 HPC 授權／核心錯誤時改 4 cores，記錄錯誤與降核心原因，不低於 4。資源預算見 [05](05-排程與串接.md#排程求解)。
