# Port 建立與求解設定

[回操作說明索引](../../操作說明.md)

## 這一章做什麼

在通道兩端建立元件端 Port，並設定掃頻範圍、自適應方式與收斂條件。
做完的 EDB 才能送進排程求解。

**沒有 Port 的通道無法排程求解，串接也會失敗。**

## 操作步驟

1. 載入通道 `.aedb`（裁切輸出，或別人切好的檔案），選好訊號與參考 Net。
2. 在「Port 設定」選類型：

   | 類型 | 用在哪 |
   |---|---|
   | **Coax（建議）** | 元件 Pin 到參考導體的同軸型 Port |
   | Circuit | 電路埠 |
   | **Pin Group（細間距 BGA）** | 負端＝該元件所有參考腳，不找座標。**整組一致，不與 Coax 混用** |

3. 按「建議端點（最多 2 個）」自動選出通道兩端的元件，再自己確認一次。
   **不要把候選元件全部勾選**——大型 BGA 會建出一大堆不必要的 Port。
4. 在「模擬設定」設掃頻與自適應方式（預設見下）。
5. 按 **「建立 Port 並套用求解器設定」**。

![模擬設定：掃頻、自適應方式與收斂條件](../../graph/模擬求解器設定示意_20260815.png)

**掃頻設定 SIwave 也會用，其他設定只有 HFSS 會用。** 每一段實際用哪個求解器
是在第 05 章的「混合求解區域」決定。

### 自適應方式：預設是寬頻

網格是照某一個頻率切的，**用低頻切出來的網格算高頻會產生假反射**。所以預設把自適應
頻率範圍自動推導成 `1 GHz ～ 掃頻上限／2`（Ansys 原廠 BKM 建議），不用手填。
另有「多頻（3 點）」與「單一頻率」；任一模式設定失敗都會退回單一頻率並記錄原因，
**不會靜默沿用預設值**。

實測佐證：用 10 GHz 單點自適應掃到 50 GHz，與 SIwave 逐點比對——**兩邊耗損幾乎一樣、
差異全在反射，而分歧起點正好落在自適應頻率上**（HFSS 本身收斂正常）。
量化數據見[自適應範圍驗證報告](../../validation/solver_mix/自適應範圍驗證報告.md)。

### 介面預設值

| 設定 | 預設值 |
|---|---|
| 掃頻模式 | `Interpolating` |
| Sweep 1／2／3 | `0～1 Hz` 2 點／`1 Hz～100 MHz` Log 20 點／`100 MHz～50 GHz` 步進 0.05 GHz |
| 自適應方式 | 寬頻（`1～25 GHz`，由掃頻上限推導） |
| 平行自適應區（PAR） | 啟用 |
| 網格方法 | `Phi Plus` |
| Error Tolerance／Max Refinement | 0.1%／15% |
| Min Converged／Max Passes／Max Delta S | 2／20／0.02 |

**這些是工具預設值，不代表適合所有板材與精度需求**，正式模擬前請照專案規格確認。

## 每個 Port 都要有參考

Port 的負端就是回流路徑。少了它，求解器不知道電流從哪裡回去。
元件端是 BGA／Solder Ball 時，工具依訊號 Pin 所在層自動找適合的參考層。

**負端會被吸附到 1 mm 內最近的參考 Via 中心。** 負端落在銅箔空曠處時
SIwave 可能把該節點當成無效直接排除，症狀是**輸出的 Touchstone Port 數比預期少、
而且沒有錯誤訊息**。A／B 實測：同一片板未修正輸出 `s8p`、修正後 `s12p`。

球距小到訊號球正下方就是 antipad 時，座標型負端站不住——**改用 Pin Group**。

## 輸出結果

- 建好元件端 Port 與 `HFSS_Setup_1`／`Sweep_1` 的 `.aedb`，可直接進第 04 章分段
  或第 05 章排程求解。
- 介面列出實際建立的 Port 與其參考層，**送出前請核對數量與預期相符**。
