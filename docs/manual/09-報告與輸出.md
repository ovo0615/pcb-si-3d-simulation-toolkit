# 一鍵 HTML 報告與輸出檔案

[回操作說明索引](../../操作說明.md)

## 這一章做什麼

把各結果畫面存成快照，加上公司品牌與結論，輸出成**單一自包含 HTML**——
圖片以 data URI 內嵌，**寄出去只有一個檔**，對方不必解壓縮、不必連網。
後半列出全部輸出檔案放在哪裡。

在入口「結果」組勾選 **☐ 一鍵 HTML 報告**（預設不勾）啟用。

![報告封面：品牌、客戶、產生時間與安全模式](../../graph/一鍵產出HTML報告_1_20260815.png)

## 操作步驟

### 1　保存快照

**快照擷取的是「目前這個分頁的畫面」**，包含縮放、平移、圖層開關與曲線選擇——
**先把畫面調成想呈現的樣子，再按快照**。

各結果分頁的分頁列右側有 **📷 更新報告快照**，按下後填兩個欄位：

- **工程狀態**：僅供展示／通過／注意／失敗。**這是給讀者的判讀結論，
  不是工具算出來的**——工具不會替你判定合格與否。
- **圖說／工程備註**：這張圖要證明什麼（可留空，稍後在報告中心補）。

可存快照的分頁：完整 Layout、裁切後 Layout、清理對比、分段（整體與逐段）、
串接電路、S 參數、IBIS 與眼圖、TDR、截面阻抗。
**畫面上有多張眼圖時，總覽以外還會替每張眼圖各存一張獨立快照**——
整頁快照只拍得到目前露出來的那一段。

- 同一個畫面最多留 5 版，第 6 次會問是否移除最舊的。報告採用你指定的那一版（預設最新）。
- **來源資料變了，對應類別的快照會被標成「過期」並附原因**，但**不會被刪除**——
  由你決定重拍或照舊採用。

### 2　報告中心

功能表「檢視 → 一鍵 HTML 報告中心」，或分頁列的「報告」。五個分頁：

| 分頁 | 做什麼 |
|---|---|
| **快照總覽** | 切換採用版本、改章節歸屬與工程狀態、排除某版、加入外部補充圖片 |
| **品牌** | 公司名稱、部門、專案、客戶、報告編號與 Logo。**可存成預設值下個案子沿用** |
| **內容與規格** | 勾選章節（沒有對應快照的自動略過）、驗收規格、分析目的與結論等文字段落 |
| **浮水印** | 文字／圖片／兩者，可調透明度、角度、排列；六顆變數按鈕插入 `{客戶名稱}` 這類佔位符 |
| **預覽與輸出** | 語言（中／英／雙語）、安全模式、輸出品質、輸出前檢查 |

**驗收規格是純文字欄位**，原樣列在報告的規格表中，**工具不會拿它去自動比對判定**。

**安全模式**：對外安全模式（預設，本機路徑替換成 `[已隱藏本機路徑]`）或內部工程模式。

**輸出品質**決定報告裡圖片的顯示寬度（精簡 1280／標準 1920／高品質 3840 px，
預設標準）。**快照本身一直是最高解析度**，要交 3840 px 的報告記得改成高品質。

### 3　產生報告

按「一鍵產生 HTML 報告」，預設輸出到工作區的 `exports/`：

```
<專案名稱>_分析報告_<YYYYMMDD>_<HHMM>.html
```

報告內建「列印／另存 PDF」與「全螢幕」，圖片可點擊放大——**要交 PDF 用瀏覽器列印即可**。

![報告內的圖：自動編號、工程狀態、圖說與可稽核資訊](../../graph/一鍵產出HTML報告_2_20260815.png)

每張圖自動編號並附**工程狀態標籤**、**圖說**、**可稽核資訊**（快照版本、產生時間、
該圖的 **SHA-256**——同一張圖有沒有被換過，比對雜湊就知道）與**來源資料表**
（訊號網路數、分段數、快照品質等，事後不必回頭猜這張圖是在什麼設定下拍的）。

## 報告工作區放在哪

**工作區跟著案子走，不會落到家目錄**（快照動輒上百 MB，而且換一片板子時兩份會混在一起）：

```
輸入是 <板子目錄>\MyBoard.aedb   →   <板子目錄>\MyBoard_report_workspace\
在欄位指定目錄 <指定目錄>\       →   <指定目錄>\report_workspace\
```

**什麼都還沒載入時工作區開不起來**——位置是從目前開著的檔推出來的，
後端寧可拒絕也不替你挑一個想不到的磁碟位置。先載入電路板或 S 參數檔，
或直接在上方欄位指定目錄。

| 項目 | 內容 |
|---|---|
| `report_manifest.json` | 快照清單、版本、章節、品牌與設定 |
| `snapshots/` | 各版本快照圖 |
| `assets/` | Logo、浮水印圖片 |
| `exports/` | 產出的 HTML 報告 |

## 輸出結果：全部檔案在哪裡

| 輸出 | 說明 |
|---|---|
| `*_Cutout.aedb` | 裁切後的通道 EDB（只有幾何，不建 Port） |
| `*_stackup.aedb`／`*_stackup_change_report.json` | 疊構更換後的新 EDB 與前後逐層狀態 |
| `*_backdrill.aedb`／`*_backdrill_report.json` | 背鑽後的新 EDB 與每顆 Via 的讀回驗證 |
| 清理後 `.aedb`／`*_cleanup_report.json` | 清理條件、候選與刪除數量 |
| `*_ports.aedb` | 含元件端 Port、HFSS Setup 與掃頻的新 EDB |
| `segment_1..N.aedb`／`segments.json` | 分段 Layout 與切面 Port／分段索引與安全驗證 |
| `segment_1..N.sNp` | 各段求解後的 Touchstone |
| `cascade_result.sNp`／`*_cascade_summary.json` | 完整通道串接結果與來源摘要 |
| `*_S參數.xlsx` | 匯的是**目前圖上那幾條曲線**，不是後端重算 |
| `tdr_results\*_tdr.aedt` | TDR 的 Circuit 專案 |
| `ibis_channel_runs\`／`ami_channel_runs\` | 每次 IBIS／AMI 分析的結果目錄 |
| `q2d_runs\*_q2d.aedt`／`*.aedb.q2dcuts.json` | Q2D 專案／框選範圍與切線集 |
| `*_report_workspace/`／`*_分析報告_*.html` | 報告工作區／單一自包含 HTML |

> **保留 `segments.json` 與所有分段 EDB／Touchstone 的相對位置，不要只移動單一檔案。**
> 那份 json 記的是相對關係，搬走其中一個後面的串接就接不回去了。
