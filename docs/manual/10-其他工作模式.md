# 其他工作模式

[回操作說明索引](../../操作說明.md)

## 這一章做什麼

四種不走標準流程的入口：手上已經是通道、只有一份外部 S 參數、沿用上次的分段、
串接別人給的 Touchstone。**第一次用請跳過整章**，照 [00 第一次跑](00-第一次跑.md) 走。

## 直接匯入既有通道進行分段

輸入檔案已經是裁切好的通道時，不必再跑一次裁切。

1. 入口勾選「載入電路板」，**但不要勾子項「局部裁切」**（要換疊構的話子項照勾）。
2. 載入檔案。這時載入鈕寫的是 **「載入檔案（不裁切）」**，說明會變成
   「此檔案將直接作為通道進入後續步驟」——**兩處對得上才是進對了模式**。
3. 選訊號與參考 Net。
4. 需要時用第 03 章建立 Port 與 Setup，再進 N 段分割。

**這個模式本身不會建立 Port 或 Setup。** 後續要排程求解與串接的話，
**來源 EDB 必須有正確的元件端 Port**，否則串接會因為沒有外部 Port 而失敗。

## 直接檢視單一外部 S 參數檔

整片板一次解完、拿到單一 `.sNp` 時不需要接線：在「電路串接」面板切到
**外部 S 參數檔**，加入該檔，按 **「直接檢視這個檔（不接線）」**。

切到差動後自動列出每一對的 IL（`Sdd21`）、RL（`Sdd11`）、
NEXT（`Sdd(受害近, 加害近)`）與 FEXT（`Sdd(受害遠, 加害近)`）。

**自動配對靠的是檔頭註解**（Touchstone 格式本身沒有 Port 名稱欄位）：

```
! Port[1] = U310.T24.SERDES_RXP.PIC4_IB2_RX_P1
! Port[2] = U310.T25.SERDES_RXN.PIC4_IB2_RX_N1
```

- **差動對**：名稱只差在 P↔N 的兩個 Port 配成一對，**對稱即可**，不限命名慣例。
- **遠近端**：看名稱第一段的元件代號，恰好兩種時先出現的是近端。

沒有註解、命名不對稱或元件不只兩種時**載入仍會成功**並在日誌說明原因，
單端檢視照常可用，只是差動曲線無法自動配對。

實測 32 port 檔（0～50 GHz、1160 點）：自動配成 8 對差動，
產生 8 條 IL、8 條 RL、28 條 NEXT、28 條 FEXT。

> **FEXT 目前每兩對只算單一方向**（A 的近端 → B 的遠端）。網路互易時 NEXT 兩個方向
> 相同，FEXT 則不然；需要反方向時只能自己拿那個 Touchstone 檔算。

### 圖表操作與匯出

圖例與軸控制收在右上角的「◀ 圖例／軸」抽屜（差動串音有 28 條，攤在圖上方會把曲線
擠出畫面）。抽屜含縮放／平移軸、Y 軸範圍、Fit All 與**匯出 Excel**。

**匯出的是畫面上當下顯示的曲線，不是後端重算**——你可能關掉了某幾類，
重算會給出跟畫面不一樣的東西。輸出含「摘要」與「S 參數 (dB)」兩張工作表，
第一欄是頻率（GHz）。**曲線頻率點不一致時改為每條一張工作表、不做內插**——
內插出來的點看起來像量到的資料，實際上是工具編的。

## 直接沿用既有的分段結果

分段一次要二十分鐘以上。只是要換求解器設定、改核心數或重打求解包時不必重跑：

1. 入口勾選「排程求解」（要打包再加勾「遠端求解包」），**不必勾「N 段分割」**。
2. 在「排程求解」面板按**瀏覽…**選先前的 `segments.json`。
3. **逐段的求解器指派會一併載入**。
4. 照常「開始排程模擬」或「匯出求解包」。

入口提示「排程求解需要 N 段分割」**只是提醒、不會阻擋**。

## 使用外部 Touchstone 檔案串接

1. 按「加入 S 參數檔（可多選）」載入至少兩個檔案。
2. 按「自動建議接線」——Port 名稱符合 `SEGk_R/L_net_i[_T/B]` 慣例時自動配對相鄰分段，
   同分段的 `T/B` 建議為短路群組；一般檔案則配對相鄰檔案中的完全同名 Port。
3. 不足時用「新增接線」逐一選兩端 Port，用「新增短路群組」處理需共節點的 Port。
4. **先按「預覽接線」確認，再按「執行串接」。**

串接前確認所有 Touchstone 的頻率範圍與頻點相容、參考阻抗與 Port 定義一致、
Port 名稱可辨識——**檔頭沒有 Port 名稱時只能以 `Port1`、`Port2` 替代**，
那時自動建議就幫不上忙。

## 輸出結果

與標準流程相同（見 [09 報告與輸出](09-報告與輸出.md)）：分段 EDB 與 `segments.json`、
各段與串接後的 Touchstone、`*_cascade_summary.json`、S 參數 Excel。
