# 第一次跑：從下載到第一張眼圖

[回操作說明索引](../../操作說明.md)

**這一份只有一條路，照著走就會跑出東西。** 分支、選項與為什麼，全部留給後面各章。
預計 30 分鐘，其中大半在等求解。

## 開始之前

需要三樣：64 位元 Windows 10／11、**Ansys Electronics Desktop 2026.1**（含
HFSS 3D Layout 或 SIwave 授權）、**64 位元 Python 3.10 或 3.12**。
其餘套件第一次啟動時自己裝。

## 1　啟動

進 `web_app` 資料夾，雙擊 `start.bat`，等瀏覽器開啟 `http://127.0.0.1:8020`。
第一次會下載套件，慢是正常的。入口畫面勾選功能後按「開始」——不確定就全選。

## 2　載入板子

左欄「輸入檔案」填 `.aedb` 路徑，按**載入電路板**。等右側出現 Layout 預覽、
左側網路清單有東西，這一步就完成了。

## 3　選訊號與參考

左列點一條訊號網路按「訊」，把 GND 按「參」。
**至少要各選一個**，否則後面沒有東西可以解。

## 4　裁切

「裁切設定」保持預設（貼合走線、擴張 2 mm），按**執行裁切**。
工具會另存一個 `_Cutout.aedb`，原始檔不動。

## 5　建 Port 與求解設定

到「Port 與求解設定」，掃頻上限填 `10GHz`（之後再依資料率調），
按 **「建立 Port 並套用求解器設定」**。

## 6　求解

按 **「開始排程模擬」**。單段通道大約幾分鐘到幾十分鐘，畫面會顯示目前階段與
已耗時間。求解期間可以切到其他分頁，不會中斷。

## 7　串接與看結果

求解完成後按**執行串接**，得到整條通道的 Touchstone。
切到「S 參數」分頁就能看見插入損耗與回波損耗——**到這裡通道模型已經完成了。**

## 8　第一張眼圖

切到「IBIS 模型與眼圖分析」：

1. 匯入一份 `.ibs`。手上沒有模型的話，展開「沒有模型？從 AEDT 內建規格產生」，
   選 PCIeG6 按**產生並匯入**。
2. 兩側各選一個模型，先按 **「快速檢驗（不需 Touchstone）」**——它用內建的理想
   通道跑一次，**先知道這對模型本來給多大的眼**。這一步幾秒鐘，卻是後面所有
   判讀的基準。
3. Touchstone 填剛才串接的結果，按 **「執行眼圖」**。

眼圖出現，跟第 2 步的基準眼一比，就知道通道吃掉了多少。第一次就跑完了。
