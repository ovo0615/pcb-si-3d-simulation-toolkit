# 開始使用

[回操作說明索引](../../操作說明.md)

## 這一章做什麼

安裝需求、啟動與關閉、入口畫面的功能勾選。第一次用請先走
[00 第一次跑](00-第一次跑.md)，這章當環境查詢用。

## 需要先裝什麼

| 名稱 | 需求 |
|---|---|
| 作業系統 | 64 位元 Windows 10／11 |
| Ansys Electronics Desktop | **只支援 2026.1**（2026.1 以下 pyedb 換成另一套實作，會不報錯地給出不同結果） |
| Ansys License | HFSS 3D Layout、SIwave 或 Circuit，依要用的功能而定 |
| Python | 3.10 或 3.12，64 位元 |
| Node.js | 18 以上，**只有要改前端才需要** |

其餘 Python 套件（fastapi、pyedb、pyaedt、scikit-rf 等）第一次啟動時自動裝進
`web_app/backend/.venv`，版本釘死在 `requirements.lock.txt`，不會動到系統 Python。

> **求解機的 AEDT 版本必須相同。** 舊版讀新版檔案不會失敗，它會照樣算完，
> 但疊構可能被誤讀而**全程沒有錯誤訊息**。求解包會比對版本並在不符時要你確認——
> 請回答 N，去求解機補裝相同版本。

## 操作步驟

1. 進 `web_app` 資料夾，雙擊 `start.bat`。
2. 等瀏覽器開啟 `http://127.0.0.1:8020`（8020 被占用時自動往上找，畫面會寫明改用哪個埠；
   要固定用 `start.bat -ListenPort 8030`）。
3. 入口畫面勾選這次要用的功能，按「開始」。不確定就按「全選」。
4. 關閉：先在介面按「停止」等 AEDT 結束，再回 PowerShell 視窗按 `Ctrl+C`。
   **只關瀏覽器不會停止服務。**

### 入口畫面的勾選

![入口畫面：勾選這次要用的項目](../../graph/入口畫面_20260815.png)

| 組別 | 項目（☑ 為預設） |
|---|---|
| 準備 | ☑ 載入電路板（子項：☑ 局部裁切　☐ 疊構更換） |
| 前處理 | ☐ 背鑽　☐ Layout 清理 |
| 分析 | ☑ 設定 Port 與求解器　☑ N 段分割　☑ 排程求解　☐ 遠端求解包 |
| 結果 | ☑ 電路串接　☑ S 參數檢視　☐ IBIS 與眼圖　☐ TDR 定位　☐ 截面阻抗　☐ HTML 報告 |

- 勾選只影響顯示，**不影響任何工作進度**；左上角「調整項目」可隨時回來改。
- 缺前置只提示、不擋你。
- 流程順序固定：載入 → 裁切 → 疊構更換 → 背鑽 → 清理 → Port → 分段 → 求解。
  **裁切這一步不建 Port**，因為 Port 必須建在最終幾何上。

## 輸出結果

- 跑起來的本機服務：介面 `http://127.0.0.1:8020`、API 文件 `/docs`。
- 每次啟動在 `web_app` 下留一份 `start_日期_時間.log`（只保留最新三份）。

## 名詞

**EDB**：Ansys 存放電路板幾何的資料庫，副檔名 `.aedb`，可以想成板子的原始檔。

**Port**：訊號進出模型的接點。沒有 Port，求解器不知道從哪裡打訊號進去、從哪裡量出來。

**Touchstone**：求解結果檔，`.s2p`／`.s4p` 這種，`sNp` 的 N 是 Port 數。

| 功能 | 目前行為 |
|---|---|
| 通道裁切 | 依訊號 Net 建立貼合走線／凸包／矩形範圍，另存裁切後 EDB |
| Port 與求解設定 | 元件端 Coax／Circuit／Pin Group Port、HFSS Setup 與 Sweep |
| 疊構更換 | 支援 Ansys Control `.xml`、`.csv`、`.json`；先比對差異，刪層要確認 |
| 背鑽 | 以連通性判斷訊號進出層，算殘樁長度與共振頻率，依目標推導鑽深 |
| Layout 清理 | 固定保護距離或 Stackup 電磁範圍兩種模式，先預覽再另存 |
| N 段分割 | 自動搜尋安全切面、建立 Gap Port，輸出分段 EDB 與 `segments.json` |
| 混合求解 | 依 0～100 的 3D 複雜度建議 SIwave 或 HFSS，可逐段覆寫 |
| 排程求解 | 依序求解各段、匯出並驗證 Touchstone；可匯出遠端求解包 |
| 電路串接 | 依 `segments.json` 自動對接切面 Port，重建完整通道 S 參數 |
| S 參數檢視 | 自動判斷兩端與差動配對，顯示 IL、RL、NEXT、FEXT |
| IBIS 與眼圖 | 受管模型與 SHA-256、DDR 多埠時序、IBIS-AMI 通道與等化掃描、量測建模 |
| TDR 定位 | 阻抗劇變依 \|dZ/dx\| 排序並標回 Layout 走線；也可匯入示波器量測波形 |
| 截面阻抗 | 從 EDB 還原該處實際截面，重建 Q2D 二維模型求阻抗 |
| HTML 報告 | 各結果畫面快照加品牌與結論，輸出單一自包含 HTML |

</details>
