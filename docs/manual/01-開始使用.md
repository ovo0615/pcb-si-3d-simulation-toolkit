## 先做這五件事

| | 做什麼 |
|---|---|
| 1 | 從 GitHub 下載 Repository，解壓縮到本機資料夾 |
| 2 | 確認電腦裝了 AEDT 2026.1，以及 64 位元的 Python 3.10 或 3.12 |
| 3 | 進入 `web_app` 資料夾，雙擊 `start.bat` |
| 4 | 第一次啟動會自己下載套件，時間看你的網路速度 |
| 5 | 瀏覽器會自動開啟 `http://127.0.0.1:8020` |

**做完就能開工。** 下面全部是細節，用到再回來查。

一般使用者**不需要裝 Node.js**。前端已經建置好放在下載包裡了。

## 這個工具能做什麼

**一句話：把一片 PCB 的一條訊號路徑，從板子檔案一路算到眼圖。**

不用背下面這張表，用到哪一項再看那一章就好。

| 階段 | 功能 | 目前行為 |
|---|---|---|
| 通道裁切 | 裁切與元件端 Port 建立 | 依訊號 Net 建立貼合走線／凸包／矩形範圍，另存裁切後 EDB，並建立 Coax／Circuit Port、HFSS Setup 與 Sweep。 |
| Port／求解器單獨設定 | 對「已裁切好」的檔案補建 Port 與 Setup | 不需重跑裁切；已經是通道的 EDB 可直接建立元件端 Port、HFSS Setup 與 Sweep。 |
| 疊構更換 | 以外部疊構檔換掉現有 Stackup | 支援 Ansys Control `.xml`、`.csv` 與 `.json`；先比對差異，會刪層時要求確認後才另存。 |
| 背鑽 | 訊號 Via 殘樁移除 | 以連通性判斷實際訊號進出層，計算殘樁長度與共振頻率，依「保留殘樁」目標推導鑽深後另存。 |
| Layout 清理 | 移除通道電磁影響範圍外的銅箔、走線與 Via | 提供固定保護距離及 Stackup 電磁範圍兩種模式；先分析與預覽，確認後才另存清理。 |
| N 段分割 | 切成 N 段並建立切面 Port | 沿通道主方向自動搜尋 X／Y 軸向直線切割位置，使切面盡量垂直於走線，輸出 N 個分段 EDB 及 `segments.json`。 |
| 排程模擬 | 依序求解所有分段 | 可整批選 HFSS 3D Layout 或 SIwave，也可用「混合求解區域」逐段指定；每段使用獨立工作階段，完成後立即匯出並驗證 Touchstone。 |
| 混合求解 | 逐段選擇求解器 | 依 0～100 的 3D 電磁複雜度建議 SIwave 或 HFSS；先建立工作副本與 Port 契約預檢，結果記錄來源與指紋以偵測過期。 |
| 電路串接 | S 參數電路串接 | 依 `segments.json` 自動對接切面 Port；Stripline 的上下參考 Port 會先短路成同一節點。 |
| S 參數檢視 | 串接結果的頻率響應 | 由 Port 名稱自動判斷兩端與差動配對，可切換單端／差動，並顯示 IL、RL、NEXT、FEXT。 |
| 外部串接 | 串接其他來源的 Touchstone | 可載入多個 `.sNp`，自動建議或手動指定接線與短路群組。 |
| Circuit／眼圖 | 輸出 PyAEDT Circuit 與快速眼圖 | 可將完整通道或 N 段展示接線輸出為 `.aedt`；2-Port／4-Port 完整通道可在確認條件後執行 QuickEye。 |
| IBIS／IBIS-AMI | 受管模型與 Tx→通道→Rx 分析 | 匯入模型時建立 SHA-256 受管副本；一般 IBIS 可跑 QuickEye／Transient，AMI 可跑 Statistical／GetWave，PAM4 只在模型明確宣告時開放。 |
| TDR 阻抗定位 | 把 TDR 阻抗劇變換算成 Layout 位置 | 以串接後 Touchstone 建立 TDR 電路並背景求解；劇變依 \|dZ/dx\| 峰值排序，換算距離後以解析度寬度標在 Layout 走線上。 |
| 一鍵 HTML 報告 | 把各結果畫面存成快照並產出報告 | 在任一結果分頁按「更新報告快照」即保存目前畫面；報告中心可加入公司品牌、浮水印、驗收規格與結論，輸出單一自包含 HTML。 |

表格裡有幾個詞會一直出現，先講清楚：

**EDB** 是 Ansys 存放電路板幾何的資料庫，副檔名 `.aedb`。你可以把它想成「板子的原始檔」。

**Port** 是訊號進出模型的接點。沒有 Port，求解器不知道要從哪裡打訊號進去、從哪裡量出來。

**Touchstone** 是求解結果的檔案，副檔名 `.s2p`、`.s4p` 這種，裡面是這條通道在各個頻率下的表現。`sNp` 的 N 就是 Port 數。

### 材料缺失時工具會怎麼做

**金屬層的材料不見了會自動補，介電材料不見了只警告。**

裁切和分段輸出時，工具會檢查疊構引用的材料。金屬層引用了不存在的導體材料時，
工具會拿 EDB 內建 copper 的導電率補建一個同名材料，這樣 AEDT 就不會跳
`material ... not found` 警告。

介電材料缺失時只會警告，**不會自動猜 Dk／Df**。導電率猜錯影響有限，
介電常數猜錯會直接讓答案錯掉，這種東西不能替你決定。

## 需要先裝什麼

| 名稱 | 需求 | 用途 |
|---|---|---|
| 作業系統 | 64 位元 Windows 10／11 | 啟動腳本、AEDT 與本機 Web 介面。 |
| Ansys Electronics Desktop | **只支援 2026.1** | EDB 讀寫、HFSS 3D Layout／SIwave 求解、Touchstone 匯出、Circuit 專案與 QuickEye。 |
| Ansys License | 須具備對應的 HFSS 3D Layout、SIwave 或 Circuit 授權 | 沒有對應授權時，相關求解流程無法開始；只輸出 Circuit 專案也需要可啟動 AEDT Circuit。 |
| Python | 3.10 或 3.12，64 位元 | 執行 FastAPI、PyEDB、PyAEDT 與 S 參數串接；兩個版本皆有實測紀錄。 |
| Node.js | 18 以上，僅開發者需要 | 一般使用者直接使用已建置的前端，不需要安裝 Node.js；只有修改前端原始碼時才需要。 |
| uv | 選用 | 加速建立 Python 虛擬環境及安裝套件；未安裝時啟動腳本會自動回退至 `venv`／`pip`。 |

## 為什麼只能用 AEDT 2026.1

**因為 2026.1 以下，pyedb 會偷偷換成另一套完全不同的實作，而它壞掉的方式不會報錯。**

pyedb 是這個工具用來讀寫板子檔案的函式庫。它後面有兩套實作：2026.1 以上走 gRPC，
以下走 .NET（要另外裝 pythonnet）。

**像是同一支遙控器換去控另一台電視。** 按鍵都還在、位置也一樣，但按下去的反應不保證相同。

我們實際比對過兩邊的 API，工具用到的東西都存在、簽章也幾乎一致，**表面上是相容的**。
真正的雷都在行為層。實例：gRPC 的 `cutout` 簽章寫著接受 `ConvexHull`（凸包），
實際跑起來只有 `Bounding`（矩形框）能用。

**這種「不報錯但結果不同」是最難查的失敗。** 所以這條界線直接寫進程式：
指定 2026.1 以前的版本會**當場被拒絕並說明原因**，不會讓你一路走到載入板子時
才丟出一句看不懂的 `Failed to initialize Dlls`。

未來 AEDT 出新版並納入支援後，介面上會自動出現版本選單。只有一個可用版本時不顯示，
因為只有一個選項的下拉選單沒有意義。

真的需要支援舊版的話，那是一個要獨立驗證的專案：裝 pythonnet、從裁切開始逐步比對結果、
把差異記錄下來。不該夾在其他工作裡順手打開。

### 求解機的版本也要一樣

**求解機用舊版 AEDT 讀新版產生的檔案，它不會失敗，它會照樣算完，只是答案是錯的。**

像是拿一把刻度錯掉的尺去量東西。量得很順，數字很漂亮，就是不對。
具體會發生的事：SIwave 的求解器 `siwave_ng` 照常跑完，但疊構被誤讀、
介電層可能整層被丟掉，S 參數不可信，而且**全程沒有任何錯誤訊息**。

工具的做法：求解包會記下產生它的 AEDT 版本，到了求解機上會比對。
求解機版本比較舊時會停下來要你確認，同時印出「這包需要哪一版」與「本機最新只有哪一版」。

> **遇到這個提示請回答 N。** 正確做法是在求解機補裝相同版本，
> 不要把來源端降版。降版換來的是一條沒人驗證過的路徑，而問題本來就出在求解機那一端。

### 想固定版本的話

```powershell
$env:PCBSI_AEDT_VERSION = "2026.1"
```

`2026R1`、`26.1`、`v261`、`261` 這幾種寫法都接受。

**指到不支援的版本會直接報錯，不會安靜地退回預設值。** 安靜退回會讓你以為已經切換，
實際上卻用了另一個版本產生檔案。

兩件要注意：

- 這個版本會用在**整條流程**：匯入、裁切、分段、求解、Touchstone 匯出。
- 那台電腦必須**真的裝了** AEDT 2026.1。只設環境變數而沒有對應的安裝，
  會拖到載入電路板時才失敗。

## 啟動時會自動裝哪些套件

**版本全部釘死，不會自動升級。** 清單在 `web_app/backend/requirements.lock.txt`。
釘死是為了避免某個套件自己升級之後 API 對不上，那種問題會在幾週後才炸出來。

| 套件 | 用途 |
|---|---|

| `uvicorn[standard]` | ASGI 伺服器。 |

| `pyedb` | EDB 匯入、裁切、Port、Setup、清理及分段處理。 |

**套件只會裝在 `web_app/backend/.venv`，不會動到你系統上的 Python。**
第一次啟動需要網路連線。

## 埠被占用時會怎樣

啟動後會用這兩個本機位址：

| 服務 | 位址 |
|---|---|
| 工具介面與後端 | `http://127.0.0.1:8020` |
| 後端 API 文件 | `http://127.0.0.1:8020/docs` |

**8020 被占用時會自動往上找**，8021、8022 這樣試下去，最多試 21 個。
畫面上會寫明改用了哪一個，瀏覽器也會開在那個位址。

若那個埠上跑的正好是本工具的另一份，就**直接沿用它**，不會再開一份。

要固定某個埠就用 `start.bat -ListenPort 8030`。**明確指定時就不會自動換**：
那是你刻意選的埠，被占用時直接報錯比默默換掉更清楚。

## 怎麼正常關掉

1. AEDT 正在排程求解的話，先在介面按「停止」，等目前的 AEDT 程序結束。
2. 回到啟動工具的 PowerShell 視窗按 `Ctrl+C`。
3. uvicorn 結束時會一併釋放 EDB 工作階段。

**只關瀏覽器不會停止服務。** 下次啟動時工具會認出那份還在跑的服務並直接沿用，
不會重複開一份。

## 啟動記錄檔

每次啟動都會在 `web_app` 底下留一份 `start_日期_時間.log`，內容是主控台的完整
輸出。視窗關掉了、或訊息長到被主控台截斷時，回頭看這個檔就好；啟動失敗一樣有。

**只留最新三份，多的在下次啟動時自動刪掉。** 出問題時要看的一定是最近幾次，
而跑十次就躺十個檔，反而看不出哪個是新的。

刪除只認 `start_日期_時間.log` 這個格式，你自己放在同一個資料夾、剛好也叫
`start` 開頭的東西不會被碰到。

## 入口畫面：先勾這次要用的項目

**工具開啟時會先問你這次要做什麼，主畫面只顯示你勾的那些。**

功能累積得多之後，一次全部攤開反而找不到要用的東西。

![入口畫面：放大標題與完整任務圖示，勾選這次要用的項目](../../graph/入口畫面_20260815.png)

清單分四組，☑ 是第一次啟動的預設：

| 組別 | 項目 |
|---|---|
| 準備 | ☑ 載入電路板（子項：☑ 局部裁切　☐ 疊構更換） |
| 前處理（選用） | ☐ 背鑽　☐ Layout 清理 |
| 分析 | ☑ 設定 Port 與求解器　☑ N 段分割　☑ 排程求解　☐ 遠端求解包 |
| 結果 | ☑ 電路串接　☑ S 參數檢視　☐ 眼圖　☐ 一鍵 HTML 報告 |

**「載入電路板」是父項目**，兩個子項只有在它被勾選時才出現。
取消勾選它就等於「這次不載入板子」，那時只能用「外部 S 參數檔」做串接與檢視。

- **局部裁切**：依訊號範圍裁出通道。**只做裁切，不建立 Port。**
- **疊構更換**：以外部疊構檔取代現有的 Stackup。**排在裁切之後、背鑽與 Port 之前。**

疊構更換的耗時跟板上 Via 數量成正比。實測某片 42 層板在**還沒裁切**的狀態下換疊構，
花了超過三十分鐘。先裁切再換，省下來的時間很可觀。

但它會改變層厚與層數，所以**必須在背鑽與建立 Port 之前完成**。

兩個子項都不勾時，工具會當作「這個檔案本身已經是分段就緒的通道」，直接進入後續步驟。
不需要另外再勾一個「直接匯入分段」，那個選項已經移除了。

### 流程順序是固定的

```
準備      載入電路板 → 局部裁切 → 疊構更換
前處理    背鑽 → Layout 清理
分析      設定 Port 與求解器 → N 段分割 → 排程求解
```

**「執行裁切」這一步不再順便建 Port。**

因為元件端的 Port 必須建立在**最終的幾何**上，而疊構更換、背鑽、Layout 清理
這三件事都會改動幾何。先建了 Port 再改幾何，Port 就白建了。

### 操作要點

- 進入主畫面後，左上角的**「調整項目」**可以隨時回到入口重新勾選。
- **改勾選不會影響任何工作進度。** 已載入的板子、選好的 Net、分段結果都保留，
  純粹是顯示切換。
- 勾選會記在這台瀏覽器（localStorage），下次開啟自動帶出。換瀏覽器或清快取後回到預設。
- 只有「全選」與「還原預設組」兩個快速鈕，沒有具名的組合範本。
- 一項都沒勾時「開始」按不下去。

**缺前置只提示，不擋你。** 例如勾了「電路串接」卻沒勾「N 段分割」，
入口下方會列出缺少的前置，但你仍然可以繼續。

因為電路串接另有「外部 S 參數檔」模式，直接載入既有的 `.sNp` 就能跑，
不需要分段、也不需要載入電路板。工具也不會替你把前置項目自動勾上，
那樣會把你不想要的面板塞回畫面。

**藏起來但還在跑的工作會留一條進度列**在畫面最上方，點一下可以回到入口重新顯示。
HFSS 動輒數十分鐘，藏起來又沒有任何提示就變成黑箱了。
