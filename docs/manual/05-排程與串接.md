## 排程求解與 Touchstone 匯出

**按一個鍵，工具會一段一段排隊解完，每解完一段就立刻匯出結果。**

分段完成後，`segments.json` 路徑會自動帶進來。

1. 確認每一段的 Layout 與切面 Port。
2. 選求解方式：整批用 HFSS 3D Layout 或 SIwave SYZ，或用「混合求解區域」逐段指定（見下）。
3. 按「開始排程模擬」。工具會依序為每一段啟動**獨立**的非圖形化求解程序。
4. 每段先跑 AEDT Design Validation，通過了才開始求解。
5. 解完立刻匯出 Touchstone，並把檔案路徑寫回 `segments.json`。
6. 介面顯示各段的狀態（等待中、求解中、待匯出、完成、失敗、已停止、已跳過）與耗時。

**每段用獨立的 AEDT，是為了避免長時間共用同一個 Desktop 造成記憶體累積，
最後讓後面的分段崩潰。** 單一分段失敗時，排程會釋放那個 AEDT，記錄錯誤後繼續下一段。

### 混合求解區域（逐段指定求解器）

**結構單純的段交給 SIwave 快速解，訊號路徑上真的有三維不連續的段才用 HFSS。**

每個 Segment 就是一個求解區域，可以各自用不同求解器，兼顧精度與時間。

**三種分段方式跑完都會出現這張表**：等分、依 3D 複雜度、不分割。
指向先前產生的 `segments.json` 也會出現。

依複雜度分段還多一件事：它在分析階段就已經決定好每段用哪一個求解器
（依據是那一格有沒有壓到偵測出來的 3D 複雜區），這張表帶的就是那個決定。
與下面的評分建議不一樣時，「指定」欄會標上 ⚠——那不是錯誤，只是提醒你
跑的不是評分建議的那一個。

![逐段 HFSS／SIwave 建議、指定與判斷原因](../../graph/混合求解設定_20260815.png)

### 求解器建議是怎麼評分的

**看的是訊號路徑上有沒有真正的三維不連續，不是板子有幾層、有幾顆 GND 縫合 Via。**

評分項目：

- **段內換層**：同一條訊號在本段的兩個切面落在不同層，中間就一定有換層過孔。
  **有沒有換層才是關鍵**，換幾條只是程度差別，所以以「存在」為主、條數為輔。
- **訊號 Via**：就算兩端同層，路徑上有訊號 Via 仍算真三維不連續。
  這是為了避免把蛇形換層誤判成均勻傳輸線。
- **元件端 Port launch**：端點元件的 launch 結構。
- 訊號自身的幾何複雜度與參考不連續。

**不列入評分的**：板子總層數、GND 縫合 Via 密度、與通道無關的元件數量。

這些東西不在訊號路徑上，SIwave 處理得很好。**把它們算進去只會把幾乎每一段都推向 HFSS**，
那就失去混合求解的意義了。

建議門檻：

| 複雜度 | 建議 |
|---|---|
| ≥ 55 | HFSS |
| 30～54 | SIwave（信心較低） |
| < 30 | SIwave（高信心） |

中間帶仍然建議 SIwave，只是信心比較低。

指定結果會直接疊在「N 段分割」的 Layout 上，綠色是 SIwave、紫色是 HFSS，
標籤同時顯示複雜度分數（見「N 段分割」的〈檢視輔助圖層〉附圖）。

### 操作方式

1. 用「套用自動建議」「全部 HFSS」「全部 SIwave」快速套用，或在「指定」欄逐段調整。
2. 把某段從建議改成另一個求解器時，介面會顯示該段的複雜度與警示，但**不會擋你**。
   要不要接受那一段的近似誤差，由你決定。
3. 排程開始前，工具會先建立**工作副本**並完成 **Port 契約預檢**，不直接改動分段原檔。
4. 求解結果會記錄來源求解器與指紋。**分段檔案或設定變更之後，
   對應的結果會被標記為過期**，避免你拿舊資料去串接。

各段狀態與耗時在執行期間持續更新，不必等整批跑完：

![排程執行中：求解區域表列出每段的建議、指定求解器與判斷原因，下方顯示該段目前階段與已耗時間](../../graph/SIwave模擬過程_20260815.png)

![排程結束：段別列出實際使用的求解器、總耗時與產出的 Touchstone 檔名](../../graph/整片求解完成_20260815.png)

完成的段會直接列出產出的 `.sNp` 檔名，求解中的段顯示目前階段與已耗時間。

### 網表連通性閘門（SIwave 模式）

**訊號被短路時，工具會在求解一開始就攔下來，不會讓你等整段掃頻跑完才發現結果不能用。**

SIwave 會在求解前先寫出 `.net` 網表。工具一偵測到那個檔穩定就檢查連通性：
不同訊號網路如果落在同一個導通區塊（代表被短路了），會立刻終止那一段。

日誌會列出最短導通路徑與可疑的長距離元件。採用 Touchstone 之前還有一次後備檢查。

### 執行中看得到什麼

排程卡片會顯示目前階段：初始網格、Adaptive Pass、Frequency Sweep 或 Touchstone 匯出。
AEDT 有提供 Monitor Data 時，也會顯示 Pass、Delta S、目前頻率與 Basis 數。

**連續 15 分鐘沒偵測到 Monitor Data 或結果檔更新時，工具只會顯示「沒有可觀測活動」警告，
不會自己停掉求解。** 因為「沒動靜」不等於「壞掉」。

無法可靠估算總工作量時，只顯示「活動中」與實際的資料計數，
**不提供假的完成百分比**。

按「停止」會終止目前分段對應的 AEDT PID，還沒開始的分段標記為已跳過。

### 解完了但 Touchstone 匯出失敗時

**不要為了單純的匯出失敗重跑那一段長時間求解。**

HFSS 求解已完成但 Touchstone 匯出失敗時，該段會標示為「待匯出」，
既有的 `.aedt`／`.aedtresults` 會保留。

可以按該段的「重新匯出」，或按「檢查並重試待匯出的 Touchstone（不重新求解）」批次處理。
工具會先隔離同名舊檔，再驗證新檔的時間、大小、格式、Port 數與頻率資料。

### 核心數與記憶體

「求解核心數」預設 4，HFSS 與 SIwave 都會套用。**超過本機核心數時工具會自動下修。**

「記憶體安全預算」預設 90%。工具會換算成實體 GB，並至少保留 4 GB 給 Windows。
**這個值目前只用於安全提示與紀錄，不是 Windows 層級的硬性記憶體封頂。**

### 排程會拒絕的資料

- 找不到 `segments.json` 或分段 EDB。
- 舊版 `segments.json` 缺少 Port／幾何安全驗證欄位。
- 分段裡有無 Reference 的 Port、幾何違規，或 Port 數量不一致。

## 遠端求解包（求解機不需安裝 Python）

**本機跑不動、或想把長時間求解丟到工作站時，打包成一個資料夾複製過去，雙擊執行。**

在入口勾選 **☐ 遠端求解包** 就會出現這個功能。

**求解機只需要裝 Ansys Electronics Desktop**，任何版本都可以，腳本會自己找。
不需要 Python，也不需要跟來源電腦同版本。

1. 完成 N 段分割（或指向既有的 `segments.json`）。
2. 在「遠端求解包」欄位指定一個**新的空資料夾**，按「匯出求解包」。
3. 把整個資料夾複製到求解機。**等複製完全結束再執行**，
   包內的 `ready.flag` 就是給你確認用的。
4. 在求解機雙擊 `run_all.bat`。
5. 跑完把 `results` 資料夾複製回來，在「求解完的資料夾」欄位指定它，按「收回結果」。

收回時會驗證 Port 數、頻點與格式，**通過才寫入** `segments.json`。之後串接與眼圖都能直接用。

### 核心數：不會被本機夾住

**用你在求解設定填的值，不受本機核心數限制。** 包本來就是要拿去別台跑的。

SIwave 段寫進 `.exec` 的 `SetNumCpus`，HFSS 段用 `ansysedt` 的 `-batchoptions` 傳入。

### HPC 授權不用事先設定

SIwave 段先試 Pack，取不到足夠授權會自動改用 Workgroup 重試。
HFSS 段一律用 `HPCLicenseType=Auto`，讓 AEDT 自己挑當下拿得到的授權。

**同一包在兩種機器上都跑得完，不必為此重新打包。**

> 實測寫死 `Pack` 反而會讓 AEDT 落到 Parametric（訊息寫「the 4 cores included
> with HPC Parametric context」）而只拿到 4 核，所以這個值不開放選擇。

### 怎麼確認真的拿到你要的核心數

**核心數不會出現在 AEDT 的訊息裡。要看授權。**

HFSS 求解本身內含 4 核，超出的每一核吃一張 `anshpc`：

```
12 核  →  8 張 anshpc          36 核  →  32 張 anshpc
```

用 Ansys License Management Center 看 `anshpc` 的用量最準。
求解跑完後，Profile 也會記下 `HPC Type` 與 `Cores`。

**打包前先確認求解機的授權池夠大**，否則 AEDT 會默默降級成拿得到的核心數。

### HFSS 段有兩個同名的 log，別看錯

| 位置 | 內容 |
|---|---|
| 包**根目錄**的 `segment_N_hfss.log` | AEDT 自己的訊息：版本、警告、授權不足、網格階段耗時。 |
| `logs\segment_N_hfss.log` | 本工具寫的進度：開到哪個 design、Port 數對不對。 |

授權不足時 `run_all.ps1` 會直接寫出「這台機器只有 N 核可用，但要求了 M 核」與建議值。
**不會只丟一句「找不到 Touchstone」**，讓你對著幾何和 Port 找一個根本不在那裡的問題。

> **HFSS 段的網格階段幾乎是單執行緒的**，實測有效核心數大約是 1。
> 這段期間 log 不會增長、CPU 也只吃一顆，**看起來很像當掉**。
> 那是正常的，核心數要進到矩陣求解才會展開。大型分段停在這裡數十分鐘並不罕見，
> 先別急著中斷。

## 電路串接

**把各段的 S 參數依切面配對接回去，還原成完整通道。**

在「本工具分段結果」模式：

1. N 段分割完成後就可以按「預覽接線」，**這時候還不需要求解或 Touchstone**。
2. 檢查各分段方塊、切面連線及 Stripline 短路節點。
3. 所有分段求解完成後，按「執行電路串接」。
4. 工具依 `segments.json` 記錄的切面配對關係對接相鄰分段。
5. Stripline 的上、下參考 Port 先短路成同一節點，再做跨段連接。
6. 完成後輸出串接後的 Touchstone。曲線切到「S 參數」分頁看
   （IL／RL／NEXT／FEXT 自動產生，單端／差動可切換）。

串接電路頁面支援滾輪縮放、左鍵拖曳平移及右下角「Fit All」。

要另存完整通道結果的話，按「一鍵另存完整 Touchstone」，在 Windows 對話框指定檔名。
**工具會依最終 Port 數自動修正成正確的 `.sNp` 副檔名。**

> 面板內原有的「Port A／Port B 手動加曲線」小圖已經移除。
> 「S 參數」分頁的自動曲線已經完整取代它。

每次串接也會在 Touchstone 旁邊輸出 `<檔名>_cascade_summary.json`，
記錄來源 Touchstone、短路群組、接線關係、最終 Port 順序、頻率範圍與輸出時間，
方便之後稽核與重現。

![分段 S 參數自動串接電路示意（圖為「不分割，整片求解」的單一區塊，四個外部 Port 直接向外伸出）](../../graph/串接電路示意圖_20260815.png)

看圖的方法：

- **虛線框**代表還沒解算的分段。
- **黃色節點**代表需要短路的 Stripline 上、下參考 Port。
- 每個分段方塊上標出那一段實際用的求解器與 Port 數（例如 `SIWAVE · 98`），
  方塊底下是來源 `.aedb` 檔名。
- 段與段之間的連線標的是對接的網路名稱。
- **頭尾兩段向外伸出的節點就是最終通道的外部 Port**，標籤即元件端 Port 名稱。

### 外部 Port 預檢

**沒有元件端 Port 的話，所有 Port 都會在串接時被內部對接掉，最終網路一個對外 Port 都不剩。**

串接前工具會先確認頭尾兩段有可對外的元件端 Port。
通道沒有經過裁切流程（或〈設定 Port 與求解器〉）建立元件端 Port 時，
**工具會在串接前就擋下並說明原因**，不會讓它走到後段才拋出一個看不出原因的錯誤。

## S 參數檢視

**串接完就切到「S 參數」分頁，曲線是自動配對好的，不用手動指定哪個 Port 對哪個。**

工具由 **Port 名稱**自動判斷哪些是近端、哪些是遠端，以及哪些 Port 構成差動對。

- **模式**：可切換**單端**與**差動**。
  - 單端：IL 是近端到遠端，RL 是近端反射。
  - 差動：先做單端到混合模式的轉換，`Sdd21` 是差模插入損耗、`Sdd11` 是差模回波損耗。
- **曲線**：可分別開關**插入損耗**、**回波損耗**、**NEXT 近端串音**、**FEXT 遠端串音**。
  串音曲線只有在辨識出兩組以上獨立通道時才會有內容。

![串接後 S 參數：六條曲線與展開的圖例／軸抽屜](../../graph/S參數展現_20260815.png)

右上角顯示目前的通道方向與 Port 組成（例如「近端 U14 → 遠端 U22｜2 條單端」），
圖下方標出資料來源的 Touchstone 路徑，方便回溯這是哪一次串接的結果。

**游標讀值**：在圖上點一下開啟，該頻率的每一條曲線數值會一併列出，連按兩下關閉。
**預設關閉是刻意的** —— 一直開著的話，游標移過去就跳出一大塊數值蓋住曲線。

**圖例／軸抽屜**：右上角的把手可以展開縮放軸模式、Y 軸範圍預設、Fit All、
匯出 Excel 與曲線清單。

**展開時繪圖區會往內收，不是被抽屜蓋住。** 被蓋住的永遠是最右邊、也就是最高頻那一段，
而那正是最常要看的地方。收起後圖就吃滿整格。

> 上圖勾了全部六條曲線（含 NEXT／FEXT），這也是為什麼要把圖例收進抽屜：
> 串音打開後最多會有 28 條曲線，圖例攤在圖上方會把整張圖擠出畫面。
