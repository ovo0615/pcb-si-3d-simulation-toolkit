# 載入電路板與裁切通道

[回操作說明索引](../../操作說明.md)

## 這一章做什麼

把板子讀進來、選訊號與參考網路、裁出只剩目標通道的 EDB。
選用步驟：疊構更換、背鑽、Layout 清理。

**順序固定：載入 → 裁切 → 疊構更換 → 背鑽 → 清理。** Port 排在最後（第 03 章），
因為前面每一步都會改動幾何。

## 載入電路板

輸入支援 `.aedb`（EDB）、`.brd`（Allegro）、`.tgz`（ODB++）。

1. 「輸入檔案」填路徑或按「瀏覽…」。
2. 按「載入電路板」。
3. 等 Net、元件與 2D 預覽出現。

![完整電路板 Layout 與右側圖層面板](../../graph/完整板Layout_20260815.png)

右側 Layers／Components／Nets 三個分頁。Layers 每層可勾 Planes、Traces、Pads、
Vias、Circuit Elements；**點欄標頭整欄一起切換**。左鍵拖曳平移、滾輪縮放、
右下「Fit All」還原。

大型板用快速預覽模式簡化畫面，**求解時用的仍是完整幾何**。

## 選擇訊號與參考網路

**兩種都要選。** 只給訊號不給參考等於只有去程沒有回程，阻抗不會對。

1. 左側清單雙擊或按「訊」加入訊號網路。
2. 按「參」把 GND／VSS 加入參考網路。
3. 右側清單雙擊移除；上方過濾欄可縮小清單。

訊號清單可用「匯出訊號清單」存成 `selected_signal_nets.txt`（每行一個 Net），
下次「匯入訊號清單」重用。比對不分大小寫。

### DDR 自動分類

DDR 一組 8～16 條，按 **「DDR 自動分類」** 讓工具依名稱分好。
**不開 AEDT、不花授權。**

![DDR 自動分類結果](../../graph/DDR自動分類_結果_20260818.png)

分成七個角色：資料訊號（DQ）、資料遮罩（DM／DQM）、選通參考 P／N（DQS）、
時脈 P／N（CK）、位址／命令、其他。

**位元組通道**（8 條資料＋1 組選通＋遮罩）在結果下方是可按的按鈕，
按一下整組加進訊號網路。配不到成對選通的組會明講——那組不能當位元組通道分析，
因為眼圖沒有共同的時間基準。

兩種情況會標出來要你確認：**同時符合多個角色**的網路、**看不出角色**的數量。
單字母位址樣式（`A0`、`A15`）只有整個名稱就是它時才算，這是刻意保守——
實測板上 `A0_GPIO`、`SEL_A0` 這類命名會讓子字串比對誤判 22 條。

![加入後：左邊 410 條沒被碰，右邊 22 條 DDR 網路](../../graph/DDR自動分類_已加入_20260818.png)

**參考網路不會被自動決定**，那是另一個判斷。

## 裁切

1. 設「向外擴張距離（mm）」。
2. 選「框選範圍形狀」：

   | 形狀 | 什麼時候用 |
   |---|---|
   | **貼合走線（預設）** | 外框沿走線轉彎，真的只向外擴張所設距離。斜向、L 形、彎折通道用這個 |
   | 凸包 | 通道接近直線時與貼合差不多。**通道一轉彎，內角會被整片包進來** |
   | 矩形 | 最保守、範圍最大 |

3. 按「分析精確裁切外框」——唯讀呼叫**與正式裁切相同**的演算法，畫出橘色虛線外框。
4. 確認外框包住訊號、端點元件與必要參考平面。
5. 指定輸出 `.aedb` 路徑，按 **「執行裁切」**。

![裁切範圍](../../graph/指定裁切區_20260815.png)

![裁切後 Layout](../../graph/裁切後Layout_20260815.png)

三種形狀都先跑唯讀預檢，**只有預檢失敗才回退**（貼合→凸包→矩形），
介面會顯示實際採用的形狀。貼合外框要求通道各段擴張後連得起來；連不起來時
加大擴張距離即可。

## 疊構更換（選用）

換板材、換銅厚或層厚的對照用。支援 `.xml`（Ansys Control）、`.csv`、`.json`。

1. 按「匯出目前疊構」取得可編輯的基準檔（選用）。
2. 指定疊構檔路徑，按 **「分析差異」**——列出新增／移除／變更的層與材料前後值。
3. 確認輸出路徑，按 **「套用疊構並另存」**。

**會刪層時介面用紅字標示並要求明確確認**，刪層會連帶讓該層走線與參考平面消失。
差異分析是唯讀的。**裁完再換會快很多**（耗時與板上 Via 數成正比），
但必須在背鑽與建 Port 之前完成。

## 背鑽（選用）

把訊號 Via 上用不到的那段孔銅鑽掉——那段殘樁會在四分之一波長對應的頻率造成陷波。

![背鑽：殘樁分析與共振預測](../../graph/背鑽示意_20260815.png)

1. 設「保留殘樁」（預設 5 mil）與「鑽頭加大」（預設 8 mil）。
2. 按 **「分析殘樁」**。
3. 檢查表格的**連接層**、背鑽側、殘樁長度與預測共振頻率。
4. 勾選要背鑽的 Via（預設全選），指定輸出路徑，按 **「寫入背鑽並另存」**。

**連接層由連通性判定**（該層有同 Net 的走線通過孔壁附近，或有同 Net 的元件焊墊），
不是 Via 的定義起訖層。比對用點到線段的距離——實測只比對頂點會漏掉連通層、
算出 2.353 mm 的假殘樁，照著鑽會**把訊號切斷**。背鑽前請確認連接層符合預期。

共振頻率是以平均 Dk 推算的估計值（±10%），用來判斷陷波有沒有被推出工作頻寬，
**不能當規格依據**。

## Layout 清理（選用）

刪掉離通道太遠、不影響結果的銅箔與 Via，讓後續分段與求解快一點。
訊號 Net、參考 Net、元件 Pin、Port 與 Stackup 都保留。

兩種模式：**固定距離**（一個容易理解的保護半徑），或**依電磁影響範圍**
（依各層訊號到最近參考層的高度與目標隔離度逐層算）。資訊不足時自動退回第一級。

1. 沒特別想法就按「帶入建議設定」（第二級、最小 0.2 mm、隔離 40 dB）。
2. 按「分析與紅框預覽」，檢查候選移除的數量與位置。
3. 指定輸出路徑，按「另存並執行…清理」。
4. 在「清理對比」頁籤用差異高亮檢視（**紅色＝移除的銅箔／走線，橘色＝移除的 Via**）。

## 輸出結果

| 步驟 | 產出 |
|---|---|
| 裁切 | `*_Cutout.aedb`（含 `HFSS_Setup_1` 與 `Sweep_1`，**無 Port**） |
| 疊構更換 | 新 `.aedb` ＋ `*_stackup_change_report.json` |
| 背鑽 | 新 `.aedb` ＋ `*_backdrill_report.json`（逐顆讀回驗證） |
| 清理 | 新 `.aedb` ＋ JSON 報告（清理前後的 Primitive／Padstack／容量） |

**每一步都另存新檔，原始 EDB 不會被覆寫。**
