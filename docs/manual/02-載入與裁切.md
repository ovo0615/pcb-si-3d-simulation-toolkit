# 載入電路板與裁切通道

> 此工具由虎門科技資深技術工程師 Jeff Hong 洪敬傑提供

[回操作說明索引](../../操作說明.md)

## 載入電路板

支援的輸入格式如下：

- EDB 資料夾：`.aedb`。
- Cadence Allegro：`.brd`。
- ODB++ 壓縮檔：`.tgz`。

操作方式：

1. 在「輸入檔案」輸入路徑，或按「瀏覽…」選取檔案。
2. 按「載入電路板」。
3. 等待 Net、元件及 2D Layout 預覽擷取完成。

大型板會使用快速預覽模式降低瀏覽器負擔，但實際 EDB 不會因此被簡化。

![完整電路板 Layout 與右側圖層面板](../../graph/完整板Layout_20260809.png)

右側面板可切換 Layers、Components、Nets 三個分頁；每一層可個別控制顯示、
填色與線框。左鍵拖曳平移、滾輪縮放，右下角「Fit All」還原完整範圍。



## 選擇訊號與參考網路

1. 左側清單雙擊 Net，或按「訊」，加入訊號網路。
2. 按「參」，將 GND／VSS 等加入參考網路。
3. 右側已選清單可雙擊移除。
4. 可在過濾欄輸入關鍵字縮小清單。

### 匯入／匯出訊號清單

- 「匯出訊號清單」會下載 `selected_signal_nets.txt`，每行一個 Net。
- 「匯入訊號清單」支援 UTF-8 文字檔；空白行與 `#` 開頭的註解會忽略。
- 匯入比對不分大小寫，但成功後會改用目前 EDB 中的正式 Net 名稱。
- 建議每個專案保留一份訊號清單，避免重複手動選取。



## 疊構更換

用外部疊構檔取代目前 EDB 的 Stackup，常用於「同一塊 Layout 換板材、換銅厚、換介電層厚度」的對照分析。實作於 `stackup_change.py`。

支援格式：

| 格式 | 說明 |
|---|---|
| `.xml` | Ansys Control XML（`http://www.ansys.com/control`），即 AEDT 疊構匯出格式；以 `pyedb.xml_parser.XmlParser` 解析。 |
| `.csv` | 逐層的層名、類型、厚度與材料。 |
| `.json` | 工具自身 `export_stackup` 匯出的疊構快照。 |

操作方式：

1. 按「匯出目前疊構」（`export_stackup`），取得一份可編輯的基準檔（選用）。
2. 指定疊構檔路徑。
3. 按 **「分析差異」**（`analyze_stackup_change`）。工具列出：
   - **新增**、**移除**、**變更**的層，以及厚度前後值（`_thickness_to_m` 會處理帶單位的字串）。
   - **材料變更**：介電常數與 `dielectric_loss_tangent` 的前後值。
4. 確認輸出為新的 `.aedb` 路徑。
5. 按 **「套用疊構並另存」**（`apply_stackup_change`）。

安全行為：

- 差異分析是唯讀的，不會改到來源 EDB。
- **若新疊構會刪掉現有層**，`requires_confirmation` 會是 `true`，介面以紅字標示並要求明確確認才能套用——刪層會連帶讓該層上的走線與參考平面消失。
- 完成後輸出 `*_stackup_change_report.json`。

> **材料屬性名稱**：損耗角正切在 pyedb 上是 `dielectric_loss_tangent`，不是 `loss_tangent`。早期讀錯屬性時，11 層會被誤報成「材料變更」，實際只有 1 層真的變了。



## 設定裁切範圍

1. 設定「向外擴張距離（mm）」。
2. 選擇裁切形狀：

   | 形狀 | 外框怎麼來 | 適用 |
   |---|---|---|
   | **貼合走線（Conforming）（預設）** | 每個訊號 primitive 各自向外擴張所設距離，再聯集起來 | 外框沿著走線轉彎，**真正只向外擴張所設距離**。斜向、L 形、彎折通道請用這個 |
   | 凸包（ConvexHull） | 取訊號幾何的凸包再向外擴張 | 通道接近直線時與貼合外框差異不大 |
   | 矩形（Bounding Box） | 訊號外接矩形再向外擴張 | 最保守、範圍最大 |

3. 按「分析精確裁切外框」，工具會唯讀呼叫與正式裁切相同的 PyEDB 外框演算法；
   完成後完整 Layout 上會出現標示為「PyEDB 精確預估」的橘色虛線外框。
4. 檢查外框是否包含訊號通道、端點元件與必要的參考平面，再執行正式裁切。

> 早期版本在尚未分析時會先畫一個「快速估算」外框。那個估算與 PyEDB 實際採用的外框差距可能很大，看起來像預覽卻不能作為判斷依據，已移除——現在只有按下分析後才會出現外框，畫面上顯示的就是真正會裁的範圍。

![依指定訊號與擴張距離產生裁切範圍](../../graph/指定裁切區_20260730-public.png)

### 為什麼預設不是凸包

**凸包依定義是凸的**：通道只要是斜向或有彎折，內側就必然被一條直線弦切過。那條弦與實際走線之間的空白區會被整片包進裁切範圍，連帶把大量無關的 Via 與銅箔一起帶進來——不是擴張距離設太大，是這個形狀本身做不到貼合。改用貼合外框即可，擴張距離不必動。

貼合外框的做法是各段走線先各自向外長出所設距離，再把重疊的部分聯集成一塊。因此**通道各段必須連得起來**；若擴張後仍是分離的數塊，PyEDB 會逐步加大擴張量嘗試合併，最終仍失敗時只會回傳面積最大的那一塊——等於安靜地把通道的一部分排除掉。工具會在預檢時逐點確認外框真的包住全部訊號幾何，發現漏掉就自動改用凸包並在介面說明；此時若仍想要貼合外框，請把擴張距離加大到讓各段連成一片。

預檢成功時，介面會顯示「貼合外框比凸包少包 N% 的面積」，可用來判斷這次值不值得換。

三種形狀都會先執行唯讀預檢。只有預檢明確失敗或外框無效時才會回退（貼合→凸包→矩形）；系統日誌及介面會顯示實際採用的裁切形狀。裁切完成後，工具會比較預估與正式外框：綠色代表共同區域、橘色代表僅預估區域、藍色代表實際多保留區域；容差由工具依外框尺寸自動決定。



## 執行裁切

這一步**只裁出通道，不建立 Port**。

1. 指定新的 `.aedb` 輸出路徑。
2. 按「執行裁切」。
3. 工具依序執行裁切、重新開啟輸出 EDB、完整性檢查，最後擷取預覽。
4. 完成後切換至「裁切後 Layout」確認結果。

> 輸出的通道**還沒有元件端 Port 與 Setup**。背鑽與 Layout 清理都排在這之後、
> 也都會改動幾何，所以 Port 要等它們做完再用〈設定 Port 與求解器〉建立。

![裁切前後的 Layout 對比](../../graph/裁切後比對_20260730.png)

![裁切後 Layout：只留下目標通道與元件端 Port](../../graph/裁切後Layout_20260809.png)

左上角的「差異填色」可切換，開啟時會把裁切前後的差異區域標示出來，
方便確認有沒有把該留的銅箔一起切掉。

安全行為：

- 原始 EDB 不會被覆寫。
- 裁切結果若缺少訊號幾何或參考平面，會被判定失敗。
- 原有 Simulation Setup 會從輸出副本移除，再建立 `HFSS_Setup_1` 與 `Sweep_1`。
- 按「停止裁切工作」後，工具會在 PyEDB 返回安全檢查點時停止，並嘗試重新載入原始 EDB；不是所有 PyEDB 呼叫都能立即中斷。



## 背鑽

移除訊號 Via 上用不到的那一段孔銅（殘樁）。殘樁是一段開路短截線，在**四分之一波長**對應的頻率會造成深陷波；把殘樁縮短就把陷波推到工作頻寬以外。實作於 `backdrill.py`。

![背鑽：殘樁分析與共振預測](../../graph/背鑽示意_20260805-public.png)

1. 設定 **保留殘樁**（`DEFAULT_TARGET_STUB_M`，預設 5 mil）與 **鑽頭加大**（`DEFAULT_DIAMETER_INCREMENT_M`，預設 8 mil，即鑽頭 = 原孔徑 + 8 mil）。
2. 按 **「分析殘樁」**（`analyze_backdrill`）。
3. 檢查表格：每顆訊號 Via 的**連接層**、背鑽側、鑽至哪一層、殘樁長度與**預測共振頻率**。
4. 勾選要背鑽的 Via（預設全選）。
5. 指定輸出 `.aedb`，按 **「寫入背鑽並另存」**（`apply_backdrill`）。

底層呼叫 `set_back_drill_by_layer(drill_to_layer, diameter, offset, from_bottom)`。

### 連通性判斷

殘樁長度取決於「訊號實際從哪一層進、哪一層出」，而不是 Via 的起訖層。`_connected_layers` 以兩個條件判定某一層是否真的有連接：

- `_routing_layers_by_net`：該層有屬於同一 Net 的走線，其到 Via 中心的最短距離落在 `孔半徑 + CONNECTION_RADIUS_MARGIN_M` 之內；距離用 `_point_to_polyline_distance`（**點到線段**），不是只比對頂點。
- `_pin_layers_near`：該層有屬於同一 Net 的元件焊墊落在同一半徑內。

兩條都是實測補上的：

- **少了 `_pin_layers_near`**：BGA 焊墊屬於 padstack 而非 modeler primitive，幾何掃描看不到。U44 的腳在 TOP、訊號由此進入貫穿孔，缺這條會把 TOP 誤判成殘樁起點，算出一整段假殘樁。
- **只比對頂點**：實測有走線的最近頂點距 Via 中心 251 µm、但最近**邊**只有 4.9 µm。只看頂點會漏掉 3 個真正連通的層，算出 2.353 mm 的假底部殘樁，照著鑽會**把訊號切斷**。

### 共振頻率

`_resonance_ghz` 以背鑽後殘樁長度與 `_average_dielectric_constant` 推算四分之一波長共振點。介面顯示的 Dk 為指示值（約 ±10%），共振頻率同屬估計值，用於判斷「陷波有沒有被推出工作頻寬」，不作為規格依據。

### 已知地雷

- **孔徑要讀 `instance.definition.hole_diameter`**，不是 `instance.hole_diameter`。後者回傳 0，會讓「原孔 + 增量」退化成只有增量（0.2032 mm，與原孔同徑），鑽頭鑽不乾淨孔壁鍍銅。正確值為 0.4064 mm。
- **讀回驗證要用 `core.get_back_drill_type(side)` 加 `get_back_drill_by_depth(side)`**。`get_backdrill_type()` 不帶參數時預設查底面，`get_back_drill_by_layer(from_bottom=False)` 對只設了底面背鑽的 Via 會回傳空層名——用這兩個 API 驗證會出現**假陰性**，把已經設好的 Via 報成未設定。
- 寫入後 `_read_back` 會逐顆驗證背鑽側與深度，並輸出 `*_backdrill_report.json`。



## Layout 清理

清理功能用於移除電磁影響範圍外的非目標銅箔、走線與 Via，以降低後續分段及求解負擔。訊號 Net、參考 Net、元件 Pin、Port 與 Stackup 會保留。

### 第一級：固定距離保守清理

- 以所選訊號幾何為中心，使用固定保護距離。
- 適合希望以容易理解的幾何距離保守清理時使用。

### 第二級：依電磁影響範圍判斷

- 依訊號層到最近參考層的高度 `h` 及目標隔離度，逐層計算保護半徑。
- 參考 Net 仍完整保留。
- Stackup 或參考層資訊不足時，會自動回退至第一級。

沒有特別設定需求時，可按「帶入建議設定」：

- 自動選擇第二級。
- 最小保護距離：0.2 mm。
- 目標隔離度：40 dB。

建議流程：

1. 按「分析與紅框預覽」。
2. 檢查候選移除數量及紅框位置。
3. 確認輸出為新的 `.aedb` 路徑。
4. 按「另存並執行…清理」。
5. 在「清理對比」頁籤使用「差異高亮」、「並排」、「清理前」或「清理後」檢視。
6. 差異高亮中，紅色代表被移除的銅箔／走線，橘色代表被移除的 Via；可依種類、Layer 及差異密集區過濾。

清理完成後會輸出 JSON 報告，並顯示清理前後的 Primitive、Padstack 及 EDB 容量。
