## 直接匯入既有通道進行分段

如果輸入檔案已經是裁切後的通道，不需要再跑一次裁切：

1. 在入口畫面勾選「載入電路板」，但**兩個子項都不勾**。
2. 載入 `.aedb`、`.brd` 或 `.tgz`。
3. 選擇訊號 Net 與參考 Net。
4. 需要時用〈設定 Port 與求解器〉建立元件端 Port 與 Setup、用〈疊構更換〉或〈背鑽〉調整，再執行 Layout 清理或直接進入 N 段分割。

> 舊版在「載入電路板」面板上另有一個「直接匯入分段」勾選框，現已移除——入口畫面
> 已經表達了同一件事，兩處各勾一次是重複的。

注意事項：

- 這個模式**本身**不會建立元件端 Port 或 HFSS Setup；需要時請勾入口的「設定 Port 與求解器」，不必為此重跑一次裁切流程。
- 若後續要排程求解與串接，來源 EDB 必須具有正確的元件端 Port 與 HFSS Setup，否則串接會因為沒有外部 Port 而失敗。
- 這個模式仍會在 N 段分割時建立切面 Port 及安全驗證資料。

## 直接檢視單一外部 S 參數檔

整片板子用 SIwave 或 HFSS **一次解完**、拿到單一 `.sNp` 時不需要接線：在「電路
串接」面板切到**外部 S 參數檔**，加入那一個檔，按**「直接檢視這個檔（不接線）」**
即可進入「S 參數」分頁。

切到**差動**之後，工具會自動列出每一對的：

| 曲線 | 混合模式參數 | 意義 |
|---|---|---|
| IL | Sdd21 | 插入損耗（同一對，近端 → 遠端） |
| RL | Sdd11 | 回波損耗（同一對，近端反射） |
| NEXT | Sdd(受害近, 加害近) | 近端串音：加害對的近端 → 受害對的**近端** |
| FEXT | Sdd(受害遠, 加害近) | 遠端串音：加害對的近端 → 受害對的**遠端** |

自動判定完全依賴 Touchstone 檔頭的 Port 名稱註解（Touchstone 格式本身沒有
Port 名稱欄位）：

```
! Port[1] = U310.T24.SERDES_RXP.PIC4_IB2_RX_P1
! Port[2] = U310.T25.SERDES_RXN.PIC4_IB2_RX_N1
```

- **差動對**：名稱只差在 P↔N 的兩個 Port 配成一對。不限定特定命名慣例，對稱
  即可（`TXP`／`TXN`、`_P0`／`_N0` 都可以）。
- **遠近端**：名稱第一段的元件代號。恰好兩種代號時，先出現的那個是近端。

檔頭沒有這段註解、命名不對稱、或元件不只兩種時，載入仍會成功並在日誌說明原因，
單端檢視照常可用，只是差動曲線無法自動配對。

實測 32 port 的 `..._Full_SIwave_STP.s32p`（0～50 GHz、1160 點）：讀到 16 條
兩端都有的網路、自動配成 8 對差動，產生 8 條 IL、8 條 RL、28 條 NEXT、28 條
FEXT；8 GHz 處最差 IL −3.15 dB、最大 RL −15.80 dB。

> FEXT 目前每兩對只算單一方向（A 的近端 → B 的遠端）。網路互易時 NEXT 兩個
> 方向相同，FEXT 則不然——需要反方向時請用「S 參數檢視」下方的手動選點加曲線。


### 圖表操作與匯出

圖例與軸控制收在圖右上角的**「◀ 圖例／軸」**抽屜裡（與 Layout 的圖層面板同一個
作法）。收起時整格都留給曲線——差動串音有 28 條，圖例攤在圖上方會把曲線整個擠
出畫面。抽屜展開時是覆蓋在圖上而不是把圖壓小，所以開合不會讓曲線跳動。

抽屜內含：

- **縮放／平移軸**：XY／X／Y，決定滾輪與拖曳作用在哪個軸。
- **Y 軸範圍**：0…−20／−40／−80／Auto。
- **Fit All**：回到自動範圍。
- **匯出 Excel**：把**目前圖上顯示的那幾條**寫成 `.xlsx`。

匯出的是畫面上當下顯示的曲線，不是後端重算一次——你可能關掉了某幾類、或手動加
了指定 Port 的曲線，重算會給出跟畫面不一樣的東西。輸出含「摘要」（來源、模式、
遠近端）與「S 參數 (dB)」兩張工作表；第一欄是頻率（GHz），之後每條曲線一欄，
可直接在 Excel 選取繪圖。

曲線的頻率點不一致時（例如手動加入了另一個檔的曲線），改為每條一張工作表，
**不做內插**：內插出來的點看起來像量到的資料，實際上是工具編的。

實測 32 port 檔的 72 條曲線（8 IL、8 RL、28 NEXT、28 FEXT）× 1160 個頻率點，
輸出為 1161 列 × 73 欄的單一工作表，約 1.1 MB。

## 直接沿用既有的分段結果

分段一次要二十分鐘以上。只是要換求解器設定、改核心數或重打一次求解包時，
不需要重跑切板與分段：

1. 入口勾選「排程求解」（要打包再加勾「遠端求解包」），不必勾「N 段分割」。
2. 在「排程求解」面板的路徑欄按**瀏覽…**，選先前產生的 `segments.json`
   （在分段輸出資料夾內，例如 `..._segments\segments.json`）。
3. 逐段的求解器指派會一併載入，「混合求解區域」表格會顯示 S1／S2／S3 各用哪一種。
4. 之後照常「開始排程模擬」或「匯出求解包」。

入口畫面會提示「排程求解需要 N 段分割」——那只是提醒，不會阻擋；指向既有的
`segments.json` 就接得起來。

## 使用外部 Touchstone 檔案串接

需要把**多個**檔案接成一條通道時，仍在同一個模式操作：

1. 按「加入 S 參數檔（可多選）」載入至少兩個 Touchstone 檔案。
2. 工具解析每個檔案的 Port 數及 Port 名稱。
3. 按「自動建議接線」：
   - 若 Port 名稱符合 `SEGk_R/L_net_i[_T/B]` 慣例，會自動配對相鄰分段。
   - 同一分段的 `T/B` Port 會建議為短路群組。
   - 一般檔案則嘗試配對相鄰檔案中的完全同名 Port。
4. 自動建議不足時，使用「新增接線」逐一選擇兩端 Port。
5. Stripline 或其他需要共節點的 Port，使用「新增短路群組」。
6. 先按「預覽接線」確認，再按「執行串接」。

串接前請確認所有 Touchstone：

- 頻率範圍及頻點相容。
- 參考阻抗及 Port 定義一致。
- Port 名稱可辨識；若檔頭沒有 Port 名稱，工具只能以 `Port1`、`Port2` 等替代。
