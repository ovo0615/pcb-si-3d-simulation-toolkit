## TDR 阻抗定位

TDR（時域反射）把通道的阻抗畫成「距離的函數」；這個功能再往前一步——把阻抗劇變的位置**標回 Layout 走線上**，直接指出「問題大概在板上這一段」。

入口介面勾選「TDR 阻抗定位」（在「結果」群組，前置是電路串接）後，「電路串接」面板會多出 TDR 設定區。

### 執行步驟

1. 完成電路串接（2-Port 單端或 4-Port 差動的完整通道 Touchstone）。
2. 確認模式與探棒 Port——探棒接在「輸入」端，TDR 距離從這一端起算；其餘 Port 以 50Ω 端接。
3. 速度來源由工具自動準備，不需輸入。主要依據是 S21 群延遲：由被探測 Net 的走線算出通道實體長度，配合相位反推有效傳播速度，再把 TDR 時間換算成沿走線距離。用求解結果實際呈現的相位延遲，可避免直接套用材料原始介電常數造成的系統性位置偏差。疊構若已載入，工具會同時準備第二組以疊構 Dk 換算的結果供對照（見下方「A 法與 B 法」）。
4. 按「執行 TDR」並確認條件。求解於背景進行，完成後自動切到「TDR」分頁。

單端模式**不限 Port 數**——4-Port 檔也可以探其中一條線，探棒 pin 以外的
Port 一律自動 50Ω 端接；差動模式需要至少 4 個 Port。

**上升時間不用填**：它由 Touchstone 的頻寬自動決定（`Tr = 0.35 / f_max`）。這是「這份 S 參數量得出來的最快邊緣」——讓使用者填更快的值只會產生假的定位精度，填更慢的值則浪費既有頻寬。

### 看結果

![TDR 分頁：Layout 標記、劇變表與 Z(距離) 曲線同一畫面](../../graph/TDR_20260815.png)

TDR 分頁分成三塊：

- **Layout 標記**：劇變位置畫成一段**解析度寬度**的走線亮帶，不是一個點。空間解析度 `v·Tr/2` 是物理極限，畫成點會暗示不存在的精度。
- **劇變表**：依反射強度（`|Γ| ≈ ΔZ/2Z`）排序，附每個劇變的距離、局部阻抗與 ΔZ。判定用的是 |dZ/dx| 峰值而非「偏離 50Ω 多少」——造成反射的是阻抗**階梯**，不是偏離。
- **阻抗曲線**：Z(距離) 曲線，劇變位置以垂直虛線對應編號；「通道終點」藍線右側是遠端反射的鏡像，不是板上的東西。

### A 法與 B 法：兩種速度來源

距離軸是由時間乘上傳播速度換算來的，而速度有兩種取法，工具**兩法並行**，結果頁上方可以切換：

| | 速度來源 | 需要什麼 |
|---|---|---|
| **A 法：群延遲** | 由 S21 相位反推有效傳播速度 | 走線幾何（要先載入電路板才算得出通道實體長度） |
| **B 法：疊構 Dk** | 由目前疊構的介電層厚度加權平均算出介電常數 | 已載入的疊構，不需輸入 |

兩者的差距本身就是資訊：**位置差多少，就代表速度的不確定性有多大**。兩法標到同一個位置時可以放心；差很多時代表疊構的 Dk 與求解結果呈現的相位延遲對不上，這時該懷疑的是 Dk 假設而不是 TDR。

匿名 SIwave 驗證案例以 A 法量得的可解析位置平均誤差為 0.66 mm、最大誤差為 1.71 mm；完整證據請見 [`validation/tdr/results/`](../../validation/tdr/results/TDR_定位驗證報告.md)。

### 與 Q2D 截面阻抗的交叉驗證

另一個獨立專案用 **Q2D 二維截面萃取**去驗同一件事，方法與本工具沒有共用假設：沿同一條線取多個截面各自算出 Z₀(x)，再與 SIwave 求解轉出的 TDR Z(x) 對照。結論與這一章的兩個設計選擇一致，值得一讀：

[Q2D 截面與 TDR 的交叉驗證](https://github.com/ovo0615/edb-q2d-cross-section-toolkit/blob/main/docs/cross-validation-tdr.md)

三個與本章直接相關的量測結果：

- **兩種方法的中位阻抗完全相同**（56.053 Ω，中位差 −0.000 Ω）。六個截面中五個落在 ±0.10 Ω（±0.19%）以內。相較之下 Hammerstad 封閉公式給出 58.9 Ω，比兩個數值解都高約 5%。
- **唯一不合的那個截面，原因正是解析度極限。** Cut4 差 1.4%（Q2D 56.815 Ω 對 TDR 56.011 Ω），來源是 0.44 mm 外一顆 Via 在參考層開出的反焊盤；那個結構只有 0.6～0.9 mm，而該案例的 TDR 空間解析度是 1.42 mm。這正是本章「標記畫成解析度寬度的亮帶而不是點」的理由——低於解析度的東西 TDR 看不見，畫成點會暗示不存在的精度。
- **微帶線上該信 A 法。** 該文以同一條線比較兩種速度：群延遲得 1.628×10⁸ m/s（εeff 3.39），疊構 Dk 4.2 得 1.463×10⁸ m/s（εeff 4.20），後者把距離軸拉長約 11% 並產生假的讀數。這與本工具驗證得到的方向相同，也是 A 法作為主要依據的原因。

> 兩份驗證用的是不同的測試件，數字不能互相套用。它們共同支持的是**方法上的兩個選擇**：距離軸用群延遲而非材料 Dk，以及標記寬度等於空間解析度。

### 分段切面的排除區

若通道是 N 段分割後串接回來的，切面接縫附近的小反射多半是分段假象而不是板上真實的劣化。落在切面排除區（切點 ± 解析度）內的標記會以灰色虛線顯示並標注「切面接縫」，表格中以 ⚠ 提示——不隱藏、但明確降級，避免追著接縫假象跑。

### 起點在哪一端

TDR 距離從探棒端起算。工具依走線幾何自動串出路徑並選定起點；若標記位置看起來像從另一端量的（例如第一個劇變的距離對應到走線尾端的結構），勾「起點在另一端」翻轉即可，不需重新求解。

### 已知限制

- 僅支援 2-Port 單端或 4-Port 差動通道；差動 TDR 量的是差模阻抗（單端的 2 倍）。
- 掃頻太疏會讓 S21 相位混疊、群延遲失效（症狀是負的延遲），錯誤訊息會附上需要的頻率間隔（`Δf < 1/(2τ)`）；請加密掃頻後重新求解。
- 外部 S 參數檔模式（未載入電路板）沒有走線幾何，無法由通道長度與群延遲換算傳播速度，因此不能進行 Layout 距離定位；請先載入電路板。
- Circuit 專案保留在 Touchstone 同層的 `tdr_results` 資料夾；TDR 求解與排程、眼圖互斥，一次只有一個 AEDT 工作。
