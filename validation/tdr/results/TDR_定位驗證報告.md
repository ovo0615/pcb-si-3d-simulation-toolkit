# TDR Layout 定位驗證報告

## 一句話結論

**把 TDR 的阻抗劇變標回 Layout 上，平均誤差 0.66 mm、最差 1.71 mm。**

比對的基準是「建模時就知道位置在哪」的幾何邊界，所以誤差是實實在在量出來的，
不是估的。

六個案例五個 PASS，第六個標成 LIMIT —— **那一個是刻意設計來撞解析度極限的**，
結構比 TDR 看得到的最小尺度還小，量不到是預期中的事，不是失敗。

下面是完整數據與方法。

---

本報告以幾何位置已知的匿名 PCB 案例、SIwave SYZ 求解結果，以及工具實際使用的 `assemble_tdr_analyses` 核心驗證 TDR 距離映射準度。

- 產生時間：2026-08-11T14:01:56+08:00
- 頻率範圍：0.1～20 GHz，步階 0.1 GHz（排除 0 Hz，後處理外插 DC）。
- 主要速度法：由 S21 群延遲反推有效傳播速度。
- 平均定位誤差：**0.66 mm**。
- 最大定位誤差：**1.71 mm**。

| 案例 | 結果 | 空間解析度（mm） | 最大定位誤差（mm） | SIwave 時間（s） |
|---|---:|---:|---:|---:|
| 均勻線控制組 | PASS | 1.54 | — | 21.1 |
| 低阻抗加寬段 | PASS | 1.55 | 1.10 | 20.8 |
| 高阻抗縮窄段 | PASS | 1.55 | 0.51 | 26.0 |
| 多重不連續 | PASS | 1.55 | 0.88 | 24.2 |
| 45° 彎折與弧長定位 | PASS | 1.58 | 1.71 | 22.0 |
| 解析度極限 | LIMIT | 1.54 | 解析度不足 | 22.1 |

## 判讀原則

1. 正式定位案例的容許誤差為 `max（2.0 mm，1.5 × 空間解析度）`。
2. 均勻線控制組應沒有內部顯著不連續。
3. 結構間距小於空間解析度時標示 `LIMIT`，不列入準度統計，也不宣稱能分辨兩個位置。
4. 距離換算只採 S21 群延遲反推的有效傳播速度，避免使用材料原始介電常數造成系統性位置偏差。
