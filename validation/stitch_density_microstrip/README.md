# 微帶線的切面縫合密度

報告：[微帶線縫合密度驗證報告](微帶線縫合密度驗證報告.md)

操作步驟：[操作說明 第 4 章〈分段與混合求解〉](../../docs/manual/04-分段與混合求解.md)

**核心結果**

> **縫合密度對微帶線的分段串接完全沒有影響。** 半徑 3 mm 內從 14 顆掃到 0 顆，
> 六條偏差曲線的最大散布只有 **9.8×10⁻⁴ dB**。
>
> **真正的代價來自切開本身**，隨頻率上升、隨刀數累加：參考面完美連續的試片
> 切一刀，0～1 GHz 只差 0.016 dB、15～20 GHz 是 2.077 dB；切兩刀在高頻是
> 一刀的 2.2 倍。
>
> **這份推翻了前一天自己的結論。** [真實板全頻對照](../segmentation/真實板全頻對照_20260817.md)
> 初版把偏差歸因給「缺少接地縫合」，那是推論不是量測。

## 為什麼要有這一份

真實板上量到微帶線切面偏差 1.5～2.7 dB，當時歸因給「缺縫合」。
**一片板的相關性不是因果**，而那個歸因正在決定工具要不要對微帶線切面降級。

stripline 那條 D 級是拿四個變體、單一變因量出來的
（[切面縫合密度驗證](../stitch_density/切面縫合密度驗證報告.md)）；
微帶線要有同等強度的證據才能改評級。結果是：**不該改，但原本的理由是錯的。**

## 兩個要一起讀的限制

- **試片在 15 GHz 以上不合格**（回波損耗 −7.44 dB @ 20 GHz），高頻的絕對數字
  只能當趨勢。主結論不受影響，因為它是同一片試片兩個變體相減。
- **「偏差首次超過 0.1 dB」這個判準對漣漪敏感、會非單調。** 這份實測一刀
  4.10 GHz、兩刀 5.45 GHz，兩刀反而「比較好」——那不是物理。排序要用最大偏差。
