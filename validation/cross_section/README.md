# 截面阻抗（Q2D）驗證

問的問題：**從 EDB 重建的二維截面算出來的阻抗，跟同一條走線的 TDR 剖面對不對得起來？**

報告：[Q2D 截面與 TDR 對照驗證報告](Q2D截面與TDR對照驗證報告.md)

**結論：對得起來。中位差 −0.015%，六條裡五條在 ±0.8% 內。**

兩個方法不共用任何假設 —— Q2D 不知道 S 參數存在，TDR 不知道疊構長什麼樣。
所以它們對得上這件事本身就是證據。

完整數字：六個截面的中位阻抗 48.617 Ω，SIwave→TDR 是 48.625 Ω。

**唯一的分歧（x = 155 mm，Q2D 低 2.68%）追出來是真的**：四顆 GND 縫合 Via
就落在切線上，L2 參考面碎成 9 段、L3 上多出兩段接地銅，
而 TDR 的空間解析度 0.502 mm 把它平滑掉了。

## 腳本

| 檔案 | 用途 |
| --- | --- |
| `tdr_profile.py` | 建立 ST_CTL 的走線路徑，確認弧長與座標的對應。 |
| `tdr_curve.py` | 由串接後的 s4p 算 TDR Z(距離)，並換算成 x 座標。 |
| `sweep_xs.py` | 沿兩段直線各取三條截面求解，組成 Z₀(x)。 |
| `probe155.py` | 比對 x = 145～165 的截面，追出離群值的成因。不需要 AEDT。 |

`results/` 收的是實跑輸出：`sweep.json`（六條截面的 RLGC 與阻抗）、`tdr_curve.json`（TDR 剖面）、`path_st_ctl.json`（走線路徑）。

## 必要環境與套件

- Ansys Electronics Desktop 2026.1，含 **Q2D Extractor** 授權。
- 本專案後端環境；腳本重用產品的 `app.cross_section` 與 `app.cross_section_q2d`。
- `pyedb`：讀 EDB 幾何與疊構。
- `scikit-rf`：讀 Touchstone、算步階響應。
- `numpy`。

`probe155.py` 只讀 EDB，不需要 Q2D 授權。

## 這份驗證不能拿來當什麼

不是這片板子的阻抗簽核。六個截面全部挑在直線段上，涵蓋不到轉角、Via 過渡與元件端 launch；兩個方法一致也只代表它們沒有共用的系統性錯誤，不代表兩者都對。詳見報告第七節。
