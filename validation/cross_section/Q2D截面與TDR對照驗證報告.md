# Q2D 截面阻抗與 TDR 的首次對照

日期：2026-08-16　對應 ADR-0051、ADR-0052、ADR-0053

## 為什麼做這項驗證

截面阻抗功能剛接上 Q2D 求解核心，需要一個「它算出來的數字有沒有意義」的答案。
**單元測試只能證明程式沒有壞掉，證明不了物理。**

## 實驗方法

拿**同一條實體走線**，用兩個沒有共用假設的方法各算一次：

| | 方法 | 產出 |
|---|---|---|
| Q2D | 從 EDB 逐層重建二維截面，Maxwell 2D Extractor 求 RLGC | 選定座標的精確 Z₀ |
| TDR | SIwave 2.5D 求解的 S 參數 → 步階響應 → Z(距離) | 沿線的阻抗剖面 |

**Q2D 不知道 S 參數存在，TDR 不知道疊構長什麼樣**，兩者唯一的共通點是那條走線。
單一個 Q2D 數字和一條 TDR 曲線不可比較，所以取六個位置組成 Z₀(x) 再對照。

受測件：示範板的 ST_CTL（走線在 L3、參考面 L2、通道長 188.83 mm），
S 參數 4 埠 0～50 GHz。Q2D 用 standard 檔位、自適應 8 GHz；AEDT 2026.1 非圖形化。
TDR 側推導出群延遲速度 1.433×10⁸ m/s、等效 Dk 4.375、上升時間 7.00 ps，
**空間解析度 0.502 mm**。

**切線放在兩段純水平的直線段內，各三條。** 這是刻意的：ADR-0051 規定夾角超過 20°
拒絕放置，而轉角本來就違反「結構沿線均勻」的前提——**挑直線段不是為了讓數字好看，
是因為斜切的數字沒有意義**。工作範圍取訊號兩側各 7 mm。

## 實驗結果

TDR 側取該座標 ±1 個空間解析度內所有取樣點的中位數。

| x (mm) | Q2D Z₀ (Ω) | TDR Z₀ (Ω) | 差 (%) |
|---:|---:|---:|---:|
| 85.0 | 48.602 | 48.435 | +0.35 |
| 95.0 | 48.608 | 48.516 | +0.19 |
| 105.0 | 48.654 | 48.615 | +0.08 |
| 145.0 | 48.644 | 48.889 | −0.50 |
| **155.0** | **47.632** | 48.945 | **−2.68** |
| 165.0 | 48.627 | 49.011 | −0.78 |

| | 中位數 |
|---|---:|
| Q2D（6 個截面） | **48.617 Ω** |
| SIwave → TDR（弧長 20～170 mm） | **48.625 Ω** |
| **中位差** | **−0.0071 Ω（−0.015%）** |

**兩個完全不共用假設的方法，中位數只差 0.015%。** 六條有五條落在 ±0.8% 內。

另有一條獨立跑的 x = 100 mm：ST_CTL 與 ST_ERROR 的單端 Z₀ 分別是 48.635 與
48.636 Ω——兩條線在該截面幾何完全相同，算出來就該一樣，**差 0.001 Ω 是座標平移
沒出錯的自洽證據**。

### 唯一的分歧：x = 155 mm

Q2D 低了 1.31 Ω（2.68%），而兩側 10 mm 的鄰居都正常。**這不是數值假象，
那個位置的截面真的不一樣**——四顆 GND 縫合 Via 距切線中心只有 0.060 mm、
焊墊半徑 0.533～1.143 mm，切線直接穿過它們：

| | x = 157（正常） | x = 155 |
|---|---|---|
| L2 參考面 | 一整片 12100 µm | **碎成 9 段** |
| L3（訊號層） | 只有兩條訊號 | **多出 1722 µm 與 1060 µm 的 GND 銅箔** |

關鍵是 L3 上那段 1060 µm 的 GND：**與 ST_CTL 邊緣只差 0.512 mm**，
同層、接地、緊鄰訊號，直接加上對地電容。而**走線本身沒有變**
（ST_CTL 在各座標全都是 202 µm），所以這不是線寬效應，是周邊環境。

TDR 在同一位置讀到 48.945 Ω，比鄰居還略高，**完全沒有反映這個下陷**——
因為那個結構（0.512 mm）小於 TDR 的空間解析度（0.502 mm 量級）。
**這正是 Q2D 相對時域方法的價值：它給的是選定截面的精確阻抗，包含遠小於時域
解析度的細節；代價是只在切的那個座標成立。**

> **有一件事這份驗證沒有做**：L2 參考面碎裂（回流減少，阻抗往上）與 L3 同層接地銅
> （電容增加，阻抗往下）方向相反，實測淨效果是往下 1.31 Ω，但**哪一項主導沒有分開
> 驗證**。目前能確定的只是截面結構真的不同。

## 這份驗證不能拿來當什麼

- **不是這片板的阻抗簽核**：示範板，六個截面全挑在直線段，涵蓋不到轉角、
  Via 過渡與元件端 launch。
- **不是 Q2D 或 TDR 的絕對精度證明**：兩者一致只代表沒有共用的系統性錯誤，
  不代表兩者都對。要談絕對值得有實測或第三個方法。
- TDR 側是單端反射（S11）推得，不是差動 TDR；求解檔位固定 standard，
  沒有掃過 fast／accurate 的差異。

重現腳本在 `validation/cross_section/`（`tdr_profile.py`、`tdr_curve.py`、
`sweep_xs.py`），需要 AEDT 2026.1 與 Q2D Extractor 授權。
