## 共通前提

- **驗證腳本一律重用產品程式碼**，不另外重寫一份演算法——重寫的版本會驗證到一個
  沒有出貨的東西。
- 需要 AEDT 2026.1 與對應授權。每個目錄的 `results/` 內含 JSON、圖表與匿名 Touchstone。
- 複雜度評分目前**沒有偵測**「跨越參考平面分割」與「開路殘段」，而那兩者才是
  SIwave 失準的真正原因。兩者都需要新的幾何分析，列為後續開發項目。
