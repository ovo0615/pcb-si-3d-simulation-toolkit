# PCB SI 3D Simulation Toolkit

PCB SI／3D Simulation Toolkit 是一套正在開發中的 PCB 高速訊號分析工具，目標是將 PCB 匯入、訊號網路選取、幾何裁切、Port 建立、分段模擬與 S 參數串接整合到單一流程。

## 目前進度

- 功能 1：PCB 匯入、網路選取、幾何裁切與 Port 建立 — 已完成。
- 功能 2：分段切割、切面 Port 與 AEDT 排程模擬 — 開發中。
- 功能 3：S 參數串接與完整通道還原 — 開發中。

## 公開版本

公開 Repository 目前提供 Web 前端展示版，用於展示 2D PCB Layout、層管理、Port 標記與 S 參數分析介面。完整後端、PyEDB／AEDT 整合與開發中功能保留於私人 Repository。

## 私人完整版本

完整前後端、測試、啟動腳本與開發文件不公開。如需完整功能、技術合作或客製化導入，請聯絡洽詢。

## 技術

React、TypeScript、Vite、FastAPI、PyEDB、AEDT HFSS 3D Layout。
